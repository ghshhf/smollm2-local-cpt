## 为什么 ECS 直传 856MB 会失败（2026-10-16 实测）
- 上传：150MB ✅(25s) / 300MB ✅(171s) / 856MB ❌(403 + broken pipe)；ECS 磁盘余 310G。
- 结论：非大小硬限，是单请求时长上限（856MB 按实测速率约需 8 分钟，撞服务端读超时）。
- 下载：150MB 下到 117MB 断流（~1MB/s）。⇒ 大文件必须 95MB 分片，上下同传。
