## 规约

1. **单文件 <100MB**：GitHub 硬限。权重统一切 95MiB/片（`99614720` 字节），命名 `*.partNN`。
2. **自校验**：每份带拼回脚本（大小断言 ± sha256），README 写清 provenance（拉取日期、对应训练阶段）。
3. **命名**：`<档位>/<阶段>_<拉取日期>/`，如 `0.2B/r4_final_20261011/`。
4. **语料不进 GitHub**（.gitignore 排除 *.jsonl）：只存本地/NAS，库内最多留 manifest。
5. **0.3B 及以后**：R6 封顶权重（done=7100，856MB）与 0.3B 扩容版（346.86M，1.4GB）到位后，建 `0.3B/`，流程同理：node1 分片上传 ECS → 本地拉回拼合 → sha256 校验 → 入目录。
