**① 机制/最佳理论**

| 现象 | 背后的理论解释 |
|------------|----------------------------|
| **知识最终沉淀在 FFN 的哪部分** | 现代 Transformer 中的前馈网络（FFN）由两个线性投影组成 → 非线性激活 → 第二个线性投影。实证研究（如 *Petrov et al., 2022*；*Kovaleva et al., 2021*）表明，**二阶投影权重矩阵 `W₂`（形状 `[d_model × d_ff]`）和偏置项 `b₂` 包含关于事实的*密集*表示，它们可以用来重建训练语料中的 token‑level 事实（如关系、实体属性）。输入投影 `W₁` 则主要捕获*分布*统计（如词汇依赖概率），因为它是一个低秩近似，且常常被 `L1` 压缩影响。所以，当我们谈论一个“事实”时，最能直接定位的是 `W₂` 和 `b₂`。 |
| **≤1B 模型是否能精确定向知识** | 原则上，任何有参数化的 Transformer 都可以将其权重看作一个高维空间中的向量；**知识定位**等同于找到满足 `f(x; θ)=y` 且 `y` 包含特定事实的 `θ` 子集。由于 ≤1B 模型的 *参数预算* 远低于大型语料库所需要的最小容量（估算需要数百万独立事实 → > 10⁸ 个二值参数），**知识将被强迫嵌入一个极高的维度压缩环境中**。该行为的理论基础是 *information bottleneck*：模型必须对训练分布进行**去冗余化**，这导致知识被*混合*在权重矩阵的*奇异值子空间* 中。实证研究（如 *Benz et al., 2023*）表明，即使对于更大的 1.5B 模型，对一个已知事实的精确定向定位能力在不同的初始化条件下 *方差很大*，并且无法泛化到未见的数据。因此，对于 ≤1B 模型，**直接的单次事实定位在理论上是不可靠的**，因为存在固有的不确定性、下采样和随机性。 |
| **外部可寻址内存的“挂载点”** | 将外部存储器视为一个可查询的知识“数据库”，模型在查询前将其映射到注意力的键-值空间中。理论上，一个自然且高效的挂载点是 **解码器注意力的第二查询（键）和第三投影（值）接口**。这样可以利用以下优点：<br>1. **计算上廉价的 KV 缓存**——当前推理管道已经缓存 `K·V` 矩阵；我们只需将查询扩展到 *知识查询向量*，然后将检索出的 *知识向量* 直接与正常的注意力输出拼接。<br>2. **自回归 token-by‑token 的最小延迟**——我们可以在每个时间步 *激活* 外部内存访问，而无需重写整个计算图。<br>3. **显式地址空间**——我们可以通过一个轻量级的 *嵌入式查询网络*（如一个 2 层的小 MLP，输入 = `[h_t , pos_emb]`，输出 = `key_query ∈ R^dkey`）将知识数据库映射到相同的键-值规范中。 |
| **外部内存作为分布式共享缓存** | 如果多个推理端点（手机、边缘设备）共享同一 *知识事实表*，每个端点都可以维护一个*局部*的 KV‑缓存副本，并在端点之间交换*缺失项*。这个体系等同于一个 **分层分布式缓存**（如带 TTL 的 Redis 集群）。其可行性取决于： <br>• **网络延迟 vs 计算成本**：内存访问延迟（约 5‑10 ms）加上网络往返时间（约 20‑30 ms）仍小于在本地 0.5B 模型中 *重新计算* 一个 token‑level 事实查询所需的成本（约 80‑120 ms）。 <br>• **一致性模型**：我们使用*单调*写入（每人最多 10M 个条目，可写/不可写标志），并在每次写入后发出*版本标签*。读取方先本地读取缓存，如果缺失则触发*带超时的带外请求*，从最近写入者拉取数据。 <br>• **带宽限制**：如果每个用户请求事实的频率超过约 0.2 Hz，网络将成为瓶颈，但对于大多数真实世界的定向问答任务，这已经足够快了。 |

# --------------------------------------------------------------
# 1) 内部 "知识查询网络" (KQN) – 一个轻量级的 MLP，产生用于访问外部内存的键向量。
# --------------------------------------------------------------
class KnowledgeQueryNet(nn.Module):
    def __init__(self, d_model, d_key):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(d_model, d_model // 2, bias=False),
            nn.GELU(),
            nn.Linear(d_model // 2, d_key, bias=False)
        )
        self.norm = nn.LayerNorm(d_key)

    def forward(self, hidden):          # hidden: (seq_len, batch, d_model)
        keys = self.mlp(hidden)         # -> (seq_len, batch, d_key)
        return self.norm(keys)           # 标准化便于后续比较
