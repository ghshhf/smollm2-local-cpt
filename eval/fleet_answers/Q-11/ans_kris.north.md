# kris.north (vendor=cohere, served=cohere/north-mini-code:free, 57.9s)

**① 机制/最佳理论**

**A. 抓取决策权（自主抓取策略）**
*理论背景* – “自主抓取”（autotelic）实质是一种**内部驱动型知识更新循环**，模型通过其自身的**元认知空洞感**来决定何时拉取外部信息。固定白名单则是一种**外部驱动型控制**，仅允许预定义的信源注入。
*权衡* – 直接使用 autotelic 的优势是它能自适应地抓取真正缺失的信息，避免无关噪声，但同时也存在两大风险：

1. **空洞感被“易混淆”触发** – 模型会因为分布漂移、短期注意力波动等原因而错误触发抓取，导致频繁无意义的网络调用。
2. **知识冗余放大** – autotelic 可能反复抓取同一内容（“网络回音室”），加剧 L2 信息天花板。

*最佳策略* – **分阶段渐进式策略**：

1. **白名单预热（第一轮）** – 运行 5k~10k token 后，对每个 token 计算 *知识得分*（见 §B.2），低于阈值的 token 对应的信源被加入 *动态白名单*。这一步骤确保初始抓取基于 *确定性* 信号，而非纯粹的自省。

2. **自主深化（后续轮次）** – 一旦白名单建立，模型开启 *autotelic 循环*，每个新 token 在白名单之外时，查询其内部空洞感（知识得分 + 注意力波动）。只有当空洞感超过 *自适应门槛* 时才触发抓取，并同步更新白名单。

*结果* – 达到 **确定性+自适应** 的平衡，降低误抓取率，同时保持对真正空白领域的覆盖。

**B. D1 漂移检测与最小过滤配置**
*理论背景* – D1（训练数据分布）随网络抓回的数据而 drift。传统的 KL 散度或最大均值绝对差（MAD）过于敏感；需要一个 *自适应高斯过程 GP 阈值*，捕捉真实 drift 与随机噪声之间的差异。

**关键参数**

| 符号 | 含义 | 默认建议 |
|------|------|----------|
| `α` | 自适应门槛（知识得分），触发抓取 | 0.25（范围 0.2~0.3） |
| `θ_KL` | KL 散度阈值（drift 触发） | 0.07 |
| `τ_GP` | GP 模型的显著性水平（相当于 2σ 置信度） | 0.9 |
| `γ` | 过滤比例上限（当 `p_drift > τ_GP` 时过滤），防止过度净化 | 0.15（即最多过滤 15% 的新 token） |
| `λ` | 反向传播衰减因子，用于平滑 GP 预测 | 0.95 |

**最小防污染管线**

1. **样本抽取** – 每 1000 token 获取一个批次（batch size=1024）。
2. **D1 分布建模** – 使用一个 **概率图**（嵌入空间的 GP），在线更新 token 嵌入的统计均值和协方差。
