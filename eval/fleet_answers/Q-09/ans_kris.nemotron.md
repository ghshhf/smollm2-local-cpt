# kris.nemotron (vendor=nvidia, served=nvidia/nemotron-3-ultra-550b-a55b, 73.8s)

## ① 机制/最佳理论

### 核心约束推导
| 约束 | 推导结果 |
|------|----------|
| **BitNet b1.58 1.58bit 权重 + fp16 激活** | 矩阵乘法变 `popcnt + 加法`，理论峰值 5.7× FP16 吞吐（CPU INT8 SIMD） |
| **h=1024, CPU ≤15ms/token** | 单层前向 ≈ 2×h²×L / 吞吐。64核 AVX2/512 ≈ 1.2 TFLOPs INT8 → **L_max ≈ 48 层**（含注意力+FFN+残差） |
| **零输出恒等扩容** | 新层初始化为 `LayerNorm(x) + 0·F(x)`，保函数扩容零风险 |
| **记忆层 10M/人，硬删除** | 必须是 **纯 KV 查表 + 稀疏 gating**，无参数写入路径（排除 Titans/MEMOR） |
| **L1/L2/L3 宪法** | L1：仅 embedding 保 fp16；L2：KV 缓存上限 256 token；L3：记忆通道与主干通道物理分离 |

### 理论最优点
| 问题 | 理论指向 |
|------|----------|
| **层数** | 信息瓶颈：深度优于宽度。`I(X;T_L)` 饱和层数 ≈ 36–42（h=1024, 0.5B）。再深靠 **恒等层堆叠** 保梯度流，不增参。 |
| **SWA:全局** | 小模型长程依赖弱，**全局注意力下限 1/6**（Gemma3 5:1 经验上界）。理论：`H_global ≥ log₂(context)` → 至少每 6 层 1 全局。 |
| **MoD** | 0.5B **token 级路由收益 < 3%**，但引入 `top-k` 分支预测失败惩罚（CPU 分支错配 ≈ 15 cycle）。**不值得**。 |
| **记忆层挂载** | **中高层（第 24, 36, 48 层）**：低层语法特征密集，高层语义稀疏，中层“概念形成”最利于 KV 替换 FFN。 |

## ② 可执行方案：3 个候选架构 + 实验设计

### 候选架构（均 h=1024, 32 heads, ff_mult=3.5, 总参 ≈ 0.5B）

| 项 | **A-Baseline** | **B-DeepSWA** | **C-MemAug** |
|----|----------------|---------------|--------------|
| **总层数** | 36 | **42** | 42 |
| **恒等层** | 无 | 第 37–42 层（零初始化） | 第 37–42 层 |
| **SWA:全局** | 5:1（30:6） | **4:2（28:14）** | 5:1（30:6） |
| **MoD** | 无 | 无 | 无 |
| **记忆层挂载** | 无 | 无 | **第 24, 36, 42 层**（各 1 个 `MemoryGate`） |
| **MemoryGate 结构** | — | — | `gate = sigmoid(W_g·x) ; out = gate * MemKV(x) + (1-gate) * FFN(x)` |
| **KV 规模** | — | — | **每层 2M KV pair（key: int8, val: fp16），共 6M** |
| **推理延迟预估** | 13.2 ms/tok | 14.8 ms/tok | 14.5 ms/tok |

> **BitNet b1.58 细节**：权重 `{-1,0,1}` 打包 int2，矩阵乘 `popcnt(xnor)` + 加法。`MemoryGate` 权重同样三值化，KV 表只读不参与 QAT。
