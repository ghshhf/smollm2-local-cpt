## 1️⃣  机制/最佳理论

| # | 原理 | 0.5B“深窄”系统的适用性 |
|---|------------|--------------------------------|
| **1. 深度 vs 宽度权衡** | **计算预算有限时，增加层数会提高表示能力，但代价是更深的计算图和更长的延迟。** 针对给定的隐藏大小 (h=1024)，我们将**总 FLOPs ≈ (2·L·h²)·N_tokens** 视为预算限制。在 64 核免费 CPU 上，每个 token 的预算 ≤ 15 ms ≈ 1.5×10⁹ 浮点运算 → **最大 L ≈ 30**（利用深度优先零输出恒等层扩展，保持 FLOPs 恒定）。 |
| **2. 滑动窗口注意力比例** | **全局注意力提供长程建模，而本地注意力则加速训练和推理。** Gemma‑3 的 5:1 比例是为 7B+ 模型设计的。在 0.5B 模型中，**参数数量越少，模型越难以容纳稀疏的长程依赖**，因此所需的全局比例应**降低**，以平衡计算量和上下文建模能力。经验上，我们预期**3:1 或 4:1** 是最佳折衷方案。 |
| **3. token 级 MoD（专家路由）** | **MoD 允许多个浅层子网络并行计算，但需要额外的路由头和门控参数。** 在 0.5B 规模下，增加路由器本身可能消耗约 5% 的参数，导致**参数效率下降**，如果上下文窗口较短，**专家负载不均衡**会导致严重的问题，因此 MoD 只有在 **≥ 1024 token 长上下文** 的任务上表现优于基线，否则弊大于利。 |
| **4. 外置可寻址 KV 记忆层** | **KV 查表可替换部分前馈网络 (FFN)，节省计算量并提供快速访问 long‑term 记忆。** 由于 FFN 是每个 token 都昂贵的计算密集型组件，因此将记忆层**插入深度中段**效果最佳：在注意力层后插入时，模型已捕获足够的表示；在更深的层中插入时，记忆的增量收益递减，且传播延迟较高。 |
