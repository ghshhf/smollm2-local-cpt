# 0.5B 融合版架构候选方案

## 先纠一个前提问题

**"加零输出恒等层严格保函数"在你选定的 BitNet b1.58 三值量化下不完全成立。** BitNet 前向是 `Q(W)x`，三值 Q 在零点附近存在量化死区（absmean 阈值外才产生 ±1）。一个全零初始化的层 `f(x)=0` 确实是恒等，但——它会让该层进入一个"零梯度陷阱"：∂L/∂W ∝ Q'(x)，而 BitNet 用 STE 时梯度确实能回传（STE 不依赖 W 的当前值），所以严格说**保函数≠学不动**。真正的风险是：加了 L 个恒等层后，前 L 步有效梯度只来自 embedding 的表征，梯度方差变大。**可执行对策：恒等层做"渐进门控"——f(x) = α·MLP(x)，α 从 0 线性 warmup 到 1（约 2k 步）**，兼顾"起点严格保函数"和"快速脱困"。这点影响后面的层数决策。

## 三个候选架构

### 候选 A：窄而浅 + 浅层记忆挂载（对照基线）

| 项 | 配置 |
|---|---|
| 层数 | 24 层（h=1024, 标准 GQA） |
| 注意力 | 纯全局，32k 滑窗都不开（基线最简） |
| MoD | 无 |
| 记忆挂载 | 挂 **L1-L6**（低层，6 层） |
| 定位 | 验证"低层记忆检索假设"的裸基线 |

### 候选 B：深窄 + MoD + 中层记忆挂载（主推）

| 项 | 配置 |
|---|---|
| 层数 | 48 层，其中 **16 层为零输出恒等扩容层**（α-warmup 2k 步），净等效深度 32 |
| 注意力 | **SWA(4k) : 全局 = 5:1**（沿用 Gemma3 比例先验） |
| MoD | 加，每 4 层 1 个 MoD 层（共 12 个），top-2 专家/共 16 专家，共享 expert 占 50% |
| 记忆挂载 | 挂 **L24 / L36 / L48**（高层 3 层） |
| 定位 | 深窄 + 计算稀疏 + 高层语义记忆 |

### 候选 C：深度优先极端版 + 对称记忆（激进对照）

| 项 | 配置 |
|---|---|
| 层数 | 64 层，其中 32 层恒等扩容（α-warmup），净等效 32 |
| 注意力 | SWA(4k):全局 = 3:1（更激进滑窗，测试小模型是否更适合局部） |
| MoD | 同 B |
| 记忆挂载 | **L16 / L32 / L48 / L64**（4 层，均匀分布） |
| 定位 | 测试深度是否单调正相关 + 记忆层数上限 |

## 实验设计

### 控制变量矩阵

```
固定量（三候选完全一致）：
├─ 词表：中文扩展词表（只加不换）
├─ 训练 token 数：3.5e9
├─ 数据配比：owner_corpus : 公开中文 : 代码 = 6:2:2
├─ 优化器：AdamW, lr=3e-4, cosine decay, warmup 2k
├─ 并行度：node1 64 核，张量并行=8，流水线并行=4
├─ BitNet 训练：QAT，absmean 量化，embedding 保持 fp16
└─ 评估：同一 test set，同 seed（3 次平均±std）

自变量：
├─ 深度：24 / 48 / 64
├─ SWA 配比：纯全局 / 5:1 / 3:1
├─ MoD：无 / 有
└─ 记忆挂载层位：低层6 / 高层3 / 均匀4
```

### 分阶段消融路线（控制变量的关键）

不要三组直接比，按 **5 个 stage** 增量消融，每 stage 只翻一个变量：

```
Stage 0 (基线)  ：候选 A 去掉记忆层 + 去掉 MoD → 纯 24 层窄模型
Stage 1 (深度)  ：A→C 架构，不加记忆、不加 MoD，只翻层数 {24,48,64}
                  └─ 回答问题①
Stage 2 (SWA)   ：固定最优层数，翻 SWA:Global {纯全局, 5:1, 3:1}
                  └─ 回答问题②
Stage 3 (MoD)   ：固定最优层数+SWA，翻 MoD {无, 有}
                  └─ 回答问题③
Stage 4 (记忆)  ：固定最优前三项，翻记忆挂载 {无, 低6, 高3, 均匀4}
                  └─ 回答问题④
```

每 stage 训练 **0.3B token 快速筛选**（≈ node1 上 2-3 天），最优配置进入下一 stage。全部最优组合再跑完整 3.5B token 验证。

**1. 能力指标（判"谁更强"）**
| 指标 | 通过线 | 说明 |
|---|---|---|
| 中文 C-Eval | Stage 4 最优 vs Stage 0 基线 **≥ +3 分** | 主指标，直接反映记忆/深度收益 |
| owner 领域 QA | 相对基线 **≥ +5 个点** | 检验记忆层是否真能"认主" |
