## ① 机制 / 最佳理论  
### 1. 校准误差为何难压？

| 维度 | 典型原因 | 机制说明 |
|------|----------|----------|
| **1. 参数容量不足** | 1B 以下模型由于权重数量有限，无法逼近理想的概率分布 | 低层特征表达受到瓶颈，即使多任务或 L2 正则不易克服 |
| **2. 训练数据分布截断** | 训练集不包含全部领域或噪声数据 | 低熵往往来源于输入中高置信度样本，NLL 高则是 OOD 或标签错误导致模型输出不合理 |
| **3. 学习率/优化器** | 最佳化过程在概率平面上停留在局部最优 | 尽管 NLL 下降，softmax 仍趋于 “尖锐”，导致熵低但未改变校准偏差 |
| **4. 量化 + 三值化** | 量化误差会在梯度传播中放大 | 三值化会改变梯度的尺度，导致从概率分布到校准指标的映射失真 |
| **5. 泛化误差** | 模型过拟合训练集导致评级尾部过低 | 低熵与高 NLL 必往往出现 OOD 的尖锐输出 |

> **结论**：校准错误的根源在于 *概率平面上的非线性压缩* 与 *训练分布与推理分布的不匹配*，二者的协同作用使微小模型难以落到单个基准点。

### 2. "高 NLL 低熵 = 系统性空洞" 的假设是否成立？

- **反例**：在 OOD 数据上，模型往往产生高 NLL（误差大）且低熵（过度自信），但并非因“缺失知识”而是 *分布漂移*。
- **理论支持点**：当训练集与测试集共享相同分布时，若模型充分学习，则高 NLL 通常伴随高熵；噪声/标签错误则可能出现异端组合。

**更优的探针设计**  
- **梯度马赛克探针**（Gradient‑Sparsity Probe）：  
  - 计算当前样本相对于每个类别 logits 的梯度幅值分布。  
  - **量化指标**：  
    ```
    G_j = |∂ℓ/∂z_j|  // loss w.r.t. logit of class j
    grad_entropy = -∑_j (G_j / ∑_k G_k) log(G_j / ∑_k G_k)
    grad_norm = ||G||₂ / ||ℓ||₂
    ```
  - **解释**：若模型在正确类别上梯度低且整体梯度几乎孤立，说明模型对当前输入“过度确定”而缺乏信息；若梯度分布均匀，则说明存在薄弱记忆区。
- **融合熵-梯度组合**（Entropy‑Gradient Joint Probe, EGJ）：  
  - 计算标准 softmax entropy + 梯度熵。  
  - 用 *线性判别* 或小 MLP 预测 “是否缺失知识”  
    `crit = sigmoid(a * entropy + b * grad_entropy + c)`

> **优点**  
> 1. 只依赖一点前向+反向，不需要额外标记数据。  
> 2. 对量化与三值化的鲁棒性更强，梯度信息易保留。  
> 3. 兼顾自信与信息缺失双重信号。
