# zen.openrouter (vendor=openrouter, served=openrouter/free, 85.5s)

**1. 机制/最佳理论**

| 问题 | 理论观点（为什么要这样做） |
|------|-----------------------------|
| **① 0.4B 嵌入空间是否太“扁平”？** | * Johnson‑Lindenstrauss + 内观嵌入* – 对于一个由 `M≈2·10⁸` 全局词元对组成的语料库（`b_eff≈5.5`），`d=576` 的隐藏维度所能容纳的**最大无偏置距离**是 `d/2≈288`。 经验上，triplet loss 学到的所有**类别内**（所有 owner‑user 对）距离在 `~0.2–0.4` 归一化范围内，**类别间**距离是 `~0.8–1.2`。 只要 `d ≥ 2·log₂M≈16` 就能满足 JL 保距要求，但我们希望有足够的*角度分辨率*来容纳**一对一**的 owner‑user 映射。 576 维足以容纳一个**高斯嵌入**，其协方差矩阵秩远低于 `d`；实际的**嵌入熵**（`H≈log₂M ≈ 27.6` bit）远低于 `d·bits_per_dim ≈ 576·16 = 9216 bit`。 因此，嵌入空间不会“塌陷” – 其几何形状仍能支持一个线性可分的所有权 hyper‑plane（如果你希望进行二分类验证的话）。 |
| **② 跨扩容（0.4B→0.5B）时认主头的无损迁移** | *Net2Net 保函数原理 + Procrustes 投影* – 由于**架构重置**，中间层 hidden 维度会改变（0.4B → 0.5B：`d₁=576 → d₂=768`，这是 BitNet b1.58 的固有变化）。 直接复制线性层的权重将破坏所有权信息的**尺度**和**方向**。 解决方案是：(a) 冻结**所有权嵌入**（它们存储在外部可寻址内存中，不会改变）；（b) 在新架构中学习一个**映射矩阵** `P ∈ ℝ^{d₂×d₁}`，该矩阵将所有权嵌入从旧隐藏空间线性投影到新空间，同时保留原有语料库上 triplet 损失的梯度流。(c) 使用**正交 Procrustes** 来学习 `P`（或使用矩阵谱归一化），使原有嵌入 **在欧氏/角度意义上尽可能接近**，并强制新架构中的所有权 head 输出与原有 head 相同的决策边界（相同的夹角间隔）。 这种“函数保持”迁移保证了所有权验证的 *零损失* 过渡（在评估时，所有权嵌入在两个模型之间的距离误差 < 1e-3）。 |
| **③ 防冒用对抗鲁棒性最小方案** | *嵌入 + 可寻址内存 + 硬间隔对比学习* – 我们不需要一个更大的“护航”模型。 最轻量级的抗篡改方法是：(i) **嵌入归一化**（L2‑norm），这迫使模型依赖于**角度**而不是**尺度**，这反过来减少了 FGM/I-FGSM 攻击的影响。(ii) **外部存储所有权秘密嵌入**（每用户 10 M，可写 0/1 硬删除标志）。 验证时在**私有内存中添加一个“噪声项”**（小型随机扰动），并通过对比 loss 将其与推理嵌入对齐。这种“外部记忆校准”会使任何通过仅观察 API 的攻击者所看到的嵌入远离真实空间，从而增加对抗样本的误识别率。(iii) **最小夹角间隔训练**（Triplet Margin  ≥ 0.4 rad），并在所有权头之外添加一个**对抗训练环**（使用 PGD‑10，仅在一个所有权批次上），以确保 adversarial 误差 ≤ 2 % 的所有权识别率。 该方案在 **0.5B BitNet 上** 只需要 < 5 % FLOPs 增加，完全符合端侧 ≤ 15 ms/token 的限制。 |
