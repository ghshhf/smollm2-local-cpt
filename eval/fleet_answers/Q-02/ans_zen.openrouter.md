# zen.openrouter (vendor=openrouter, served=openrouter/free, 28.8s)

**① 机制/最佳理论**  
- **为什么校准误差难压**：  
  1. **容量瓶颈**：≤1B 参数的 Transformer 在分布外数据上缺乏足够的自由度来学习真实的条件概率 \(p(y|x)\)，导致模型在低频或未见事实上输出过尖锐（低熵）却错误的分布。  
  2. **温度缩放的局限**：温度只能对整体 logits 进行线性缩放，无法纠正 **特征表示** 与 **真实标签** 之间的系统性偏差（例如嵌入空间中的“空洞区域”）。  
  3. **标签噪声与长尾**：训练语料中长尾事实很少，模型在尾部上只能依赖先验，因而产生高置信度低正确率的现象。  
  4. **度量不匹配**：NLL（负对数似然）衡量的是 **模型对真实 token 的惊讶
