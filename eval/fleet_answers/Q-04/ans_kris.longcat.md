## ① STE「数学不成立但实证有效」的解释理论

STE 的数学病灶很明确：$\frac{\partial \text{sign}(x)}{\partial x} = 0$ a.e.，而 STE 强行令其等于 1，这在函数意义下是**错误的梯度**，不指向任何下降方向。它却 work，主流解释有五层，我按对你们最相关的排序：

**1. 代理梯度 / 期望梯度视角（Bengio 2013 原始论证）**
STE 不是真梯度，而是 $\nabla_x \tilde{L}$（损失对 pre-activation 的偏导）的**无偏但有噪的估计器**。只要量化器在小扰动下符号翻转是零均值噪声，期望意义下更新方向正确。可证条件：量化步长 $\Delta$ 相对 pre-activation 标准差足够小，使局部线性近似成立。

**2. 连续松弛等价（Yin et al. 2019, "Understanding Straight-Through Estimator"）**
STE 等价于在量化函数外层包一个**恒等连续松弛** $Q_{soft}(x) = x + \text{stop-gradient}(\text{sign}(x)-x)$，再证明该松弛在特定条件下是原离散问题的一个**上界/可微替代**（surrogate）。这解释了为何它比“伪梯度”这个贬义更正面。

**3. 噪声注入 / 隐式正则**
sign 的量化误差在前向是确定性噪声，STE 把它传回后等价于给权重更新注入各向同性噪声。对非凸的 LLM loss landscape，这**有助于逃离尖锐极小值**——这跟你们 b_eff≈5.5 的小算力预算下其实有利（不需要额外加正则项）。

**4. 与随机舍入的等价关系**
三值随机舍入（round-to-nearest with probability）在期望下等于 STE 路径，这给了一个**概率意义上的合法性**：训练时的期望前向 = 推理时的确定性前向。

**5. 信息瓶颈视角**
三值只保留 1.58 bit，强行压缩反而抹掉了 pre-activation 里的细粒度冗余，留下的是对下游 loss 更鲁棒的“方向信息”。

> 对你们的关键含义：**理论 2（surrogate 上界）给了“何时会失效”的判据**——当 $\Delta/\sigma_x$ 过大（pre-activation 幅度分布太扁或步长太粗），连续松弛不再贴近离散原问题，代理梯度失去“上界替代”地位，训练开始崩。这条直接对应你第 ②③ 问。

## ② 三值 QAT 失败的临界条件

| 维度 | 临界下限 | 失效机理 |
|---|---|---|
| **模型规模** | < ~100M 时三值纯从头训**风险显著升高**（BitNet 原论文 100M 级可跑但需谨慎）。你们 0.5B 属于**安全区**，但你们是 BitNet **从头训**（0.5B 融合版架构层从头）——风险点不在参数量，而在**没有预训练权重兜底** | 小模型参数冗余度低，sign 抹掉的冗余是**功能性的**而非冗余性的 |
| **数据量** | 三值从头训需 ≥ ~100B token 才能逼近全精度基线（BitNet b1.58 论文 2T token 目标）。若你们自有资料 < 10B token 级，**必须靠你们设计的“从 0.4B 蒸馏继承”补数据缺口**，否则通用能力崩 | |
| **任务类型** | 高风险：① 需要**细粒度数值/符号运算**（数学、代码、日期），三值抹掉的小幅 pre-activation 差异是这些任务的命脉；② **长程精确检索**（你们的 owner_corpus / 10M 记忆若靠模型内记忆，三值会丢）；③ 多步推理链 | sign 在 pre-activation 接近 0 的样本上**符号不稳定**，而数学/代码 token 往往落在这个边界区 |
| **架构耦合** | BitNet 把 norm 换成 **RMSNorm 且无 mean-shift**、用 **absmax 量化**（而非 per-channel scale）。若你们 L1 压缩准入规则和 absmax 冲突，会出现**量化尺度漂移** | |

**结论**：你们的 0.5B + BitNet 从头 + 少量自有中文语料这个组合，**最大风险不是“三值化在小模型上崩”，而是“从头 BitNet + 数据不足导致三值化把通用语言能力先验抹没了”**。这恰好被你们的蒸馏继承设计对冲——所以第 ④ 问的 proxy 必须能把「蒸馏缺失」这个变量也放进去。
