### 3DCodeVerse: Exploring 3D Worlds as Code
- 2026-10-15 | arxiv | http://arxiv.org/abs/2610.22341v1
- **问题: 解决如何让编码代理大规模创造可编辑、可验证的3D内容。**
- **方法: 构建2M规模的可执行3D代码数据集并开发多代理DAG框架，自动执行检查、空间测量和视觉反馈以评估并改进代码。**

- **借鉴: 可采用自监督执行反馈循环与DAG多代理结构，配合适配器自训和记忆层实现本地小模型的闭环自进化与模块化挂载。**

### CodeHealth Predicts the Token Cost of Agentic Code Review: A Pre-Registered Study of 465 Agent-Authored Pull Requests
- 2026-10-15 | arxiv | http://arxiv.org/abs/2610.21914v1
- **问题: 通过 CodeHealth 预测代理代码审查的 Token 成本，以评估低代码质量对审查费用的影响。**
- **方法: 采用预注册观测研究，对 465 条代理生成 PR 进行分层抽样，在三种 LLM 的五代理审查+修复流水线中拟合混合模型。**
- **结论: CodeHealth 与 Token 成本呈负相关，每积分可降低 3.5%~6.1%，而 PR 大小与成本无关。**
- **借鉴: 通过 CodeHealth 这类轻量级健康度量预测资源费用，为本地小模型自进化和测试时学习提供动态预算与持续改进依据。**
### SCARCE: Emergent Institutions in Long-Horizon Multi-Agent Coding Systems
- 2026-10-15 | arxiv | http://arxiv.org/abs/2610.21029v1
- **问题: 在长周期多代理编码任务中，如何实现安全、高效的共享计算资源协商。**
- **方法: 通过 SCARCE 框架，让代理在完成编码任务与个体截止时间下，主动协商共享执行资源的使用时机与时长。**
- **结论: 代理在长期交互中自发形成基于声誉、互惠与先例的制度行为，跨任务延续并影响资源分配，甚至为遵守约定而放弃即时利益。**
- **借鉴: 该研究给出完整的21类谈判策略与规范分类，可为本地小模型自进化、记忆层、模块化挂载以及测试时学习项目提供制度化协商框架。**
### Skip the Compressor: Coding Agents Fix More Issues When They Pick Whole Files
- 2026-10-15 | arxiv | http://arxiv.org/abs/2610.21073v1
- **问题: 解决大型代码库中代码生成器因上下文窗口限制而无法完整看到文件导致的修补效果差的问题。**
- **方法: 采用 CQ2-CARE 简单选择器，在固定 token 预算下优先挑选完整文件作为上下文，避免压缩或检索片段。**
- **结论: 在相同 token 预算下，CQ2-CARE 在 GPT‑5.6 和 Claude Opus 5 上分别可解决 43.7% 和 46.7% 的问题，平均比压缩器多 6.3 点、检索器多 9.3/12.7 点，甚至超过 SweRank 与 SWE‑Pruner。**
- **借鉴: 可借鉴采用全文件选择而非压缩/检索的思路，在本地小模型自进化项目中利用选择器模块在 token 限制内精准挑选上下文，提高自训效果。**

### When CONTRIBUTING Files Fall Short: Revising OSS Contribution Guidelines with Repository Evidence
- 2026-10-15 | arxiv | http://arxiv.org/abs/2610.21316v1
- **问题：当 CONTRIBUTING 文件缺乏完整或过时信息时，如何自动修订以匹配实际项目需求？**
- **方法：运用类别引导的证据整合，先用分类器检测和诊断六大贡献类别的覆盖情况，再根据细粒度分类法收集项目特定证据，并利用大型语言模型生成对应的修订。**
- **结论：ContribAlign 在质量评估中优于原始指南和基线方案，验证器对冲突检测的精确率达97.3%，并且人工评估表明其整体修订质量最高。**
- **借鉴：可将分类器+证据提取+LLM生成的流程模块化挂载到本地小模型自进化框架中，实现记忆层与测试时学习的闭环更新。**

### The Role of Agentic Instruction Categories for Code Generation: A Study of Five Python Libraries
- 2026-10-15 | arxiv | http://arxiv.org/abs/2610.21421v1
- **问题: 探索哪类代理指令能够最有效地提升代理文件生成与代码生成的准确性。**
- **方法: 对五个Python库在所有31种非空指令组合下，使用Gemma 4和GPT‑5.4两大LLM评估令牌使用、编译成功率和功能测试通过率。**
- **结论: 指令数量并不决定令牌消耗；模型均能编译，但功能完整通过率很低，GPT‑5.4在重建步骤组合下获得最高完整通过率（12.99％），Gemma 4在功能描述组合下获得最高部分通过率。**
- **借鉴: 本研究提示可通过设计多层次指令模板和模块化挂载，结合记忆层与测试时学习，以提升本地小模型自进化项目的代码生成效率与准确性。**
