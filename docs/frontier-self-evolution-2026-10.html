一、RSI / 大模型自进化 前沿全景

1. RSI 自主框架（The Last AI Built by Humans, arXiv 2609.11873, 2026-09）

把自进化按自主程度拆成五级，是迄今最清晰的结构化框架：

级别定义我们主线对应
L0任务内迭代（Self-Refine，几轮就饱和）已有雏形
L1 执行自主跑人类写好的改进配方，更新持久化chain_v1.sh 热升级 / 看门狗
L2 策略自主自主诊断弱点、选改进方式（固定外部目标）Gate 系统（部分）
L3 经验获取自主自主定学习议程、造练习任务/课程SEAL 简化版（自造题自解自验）
L4 环境适应自主按部署反馈持续改内部状态/记忆/技能记忆层 Tier-E/Tier-P
L5 元改进自主改「改进本身的机制」（自己的 code improver / 评测器）自编辑 + 外层 RL（末位）

两个关键警示，与我们 Gate 设计直接咬合：

  • Circularity Problem（L5 致命伤）：若 AI 同时进化 solver 和 evaluator，会偷偷优化「更易的裁判」而非真更强的 solver。解法=评分无关的结构性/对比性审计。→ 我们已在 vision-0.5B-fusion.md 用「Gate 1 与 RSI 互斥、闭环期改 Gate 8 地板判据」部分应对，但评测器本身不可被闭环修改这条应写成硬规则。
  • Safe Inheritance：14% 的 Gödel Agent 试验回归到基线以下——必须有强 rollback。→ 我们保函数扩容链（逐位恒等）正是天然 rollback（旧权重永远可还原），这点比它们稳。
  • HCI 指数：到 2026 数学/科学前沿 HCI≈86.4，但 tool agent 仅 39.9 —— 交互式、状态化能力是自进化最佳落点（与我们的「端侧常驻个人服务」定位一致）。

2. 工程化实证（此前未关注 · 重要）

未关注OpenRSI（清华 + Frontis, 2026-08）：35B 模型，单张 RTX 4090（限 12GB 显存）、每任务 12 小时，在 MLE-Bench Lite 上把 Medal Average 从 39.39% 拉到 60.61%，超过 GPT-5.5 + Codex，逼近 2.8T 的 Kimi K3。核心=四个原子算子 Draft / Improve / Debug / Crossover，模型成为自己进化框架的「变异引擎」。作者明确边界：当前是 meta 自进化（第三级），不声称通用 RSI 已解决。

未关注BigBang-V1（无尽前沿, 2026-08）：号称「首个以递归自进化原生方式训练出的基座」，后训练数据 100% 由 AI 自主合成，以可验证的前沿科学任务为核心打破「合成数据坍缩」。35B 总参（激活约 3B MoE），拿 35B 模型 10 项第一，在 FrontierScience / PaperBench 上超过 1T 级的 DeepSeek V4 Pro Preview。关键机制：数据生产系统本身是被优化对象，人类角色压缩到「定目标、定预算、划边界、做验收」，AI 不能自行修改评测标准。

对我们含义：自进化已经「能跑」而非「纸上」。且两者都用可验证性兜底对抗坍缩——这与我们 0.4B 数据方案的「外部 holdout + 可验证任务」哲学同源，可参考其把「人类只做验收」落地的工程结构。

3. 自省阈值（arXiv 2607.04277, 2026-06）

从 Kleene 第二递归定理 + von Neumann 自复制复杂度阈值出发，论证可持续 RSI 需要「内省」（系统模拟自身操作并定位修改的能力）。结论：当前 LLM 只有 quasi-introspection（部分元认知），卡在三个结构瓶颈——不完全自访问、Transformer 前馈性、计算深度受限。这解释了为什么 Self-Refine 几轮就饱和。→ 我们本地小模型靠「保函数扩容链」绕开了「自访问权重」问题（外部脚本改结构、权重逐位带走），但这篇提示：真正的 L5 元改进需要架构级内省能力，不是简单堆参数。

4. RSI 综述（Recursive Self-Improvement in AI, 2026-07）

覆盖 2024–2026 共 1250 篇 arXiv（74% 发表于 2026），按「改进对象 × 自动闭环程度」分四方向：输出优化 / 训练策略改进 / 评价器改进 / 自动化研究。关键结论：多数成果仍属有限自改进——代码执行、数学证明、规则检查能提供可靠反馈；开放式研究中模型自评易形成自我确认、能力坍缩、多样性下降，选题与评价标准仍主要由人类决定。→ 印证我们 L2 信息天花板（RSI 能力上限 = 语料相对先验可压缩信息量）。

二、持续学习 / 记忆层 前沿（直接对标我们的 E-7 / Gate 7）

1. CellularFlow（Show HN, 2026）· 未关注

未关注用联想记忆替代密集 FFN：Multi-Head Associative DNA Memory + Episodic Memory Slot Buffer。抗灾难性遗忘 83.9% 保留 vs 标准 Transformer 61.8%。三种模式：

  • Mode 1 Live Learning：推理时 EMA 前向更新记忆，零反向传播（与 Metis「梯度免费单次前向更新」同源）。
  • Mode 2 Selective Fine-Tune：冻结 ~85% 主干，只训记忆库。
  • Mode 3 Episodic Fact Injection：情景槽写入 + 时间衰减 exp(-0.005·age)。

记忆槽可寻址、可剪枝、离散——直接验证我们 Gate 7 删除演练（DC-2「删除后输出逐位等于从未写入是定理」）在架构上是可实现的。GitHub: celcilin/cellularflow。

2. Memini（arXiv 2605.05097, 2026-05）· 未关注

外部记忆建成有向联想图，每条边带 fast / slow 两个耦合变量（Benna-Fusi 突触巩固模型）。微分方程： dw_fast/dt = -w_fast/τ_fast + C(w_slow - w_fast) + I(t)，slow 同理。→ 情景敏感性、渐进巩固、选择性遗忘全部作为单一机制的涌现，不是硬编码删除规则。

对我们含义：我们 Tier-E（会话级 TTT，会话结束即消失）+ Tier-P（持久层，删除地址=bit-exact）的「硬切换」可以升级为 Memini 式耦合动力学——近期记忆自动衰减、反复确认才沉淀为长期，删除权仍由 DC-2（梯度贡献恒为 0）保证定理级成立。比「手动分层」更优雅。

3. 遗忘是「低秩可及性崩溃」而非「信息丢失」（Tel Aviv, 2026-06）· 未关注

理论突破：50–90% 的遗忘能量集中在 NTK 的 1–6 个 eigenmodes，遗忘是低秩的可达性崩溃，不是信息湮灭；遗忘的知识保存在 ~8 维稳定子空间，主角度漂移是复原性的主导预测。→ 改写我们 Gate 7 删除演练哲学：与其追求「删一条记忆」，不如追求「记忆表示的重排/再巩固」——因为信息没丢，只是取不到了。这与 E-7「可寻址可删除」不冲突（DC-2 仍是硬需求），但给了我们一个更宽松的实现路径：扰动特定 eigenmode 即可让某条记忆「不可达」而不触权重。

4. Nested Learning / Hope（Google, 2026）· 未关注

把记忆重定义为连续记忆系统 continuum：多个以各自频率更新的模块（快 bank 存即时信息、慢 bank 长期巩固），模型在自参考循环里优化自身记忆。Proof-of-concept 架构 Hope 用快/慢 bank。→ 与我们「记忆层自组织」目标一致，且给出「频率分离」的具体实现。

5. 清华三招（LOKI / Retrievable Gradients / DMoE, 2026-07）

  • LOKI：动态选重要层 + 把梯度投影到权重零空间（null-space），免先验样本/预处理保旧知。
  • Retrievable Gradients：梯度作为可检索、查询相关的知识单元存进 Gradient Bank，解耦「知识注入」与「永久权重修改」。
  • DMoE：专家与路由器解耦于基座 LLM，独立可更新的知识模块 + 不确定性感知路由。

三者都指向同一结论：遗忘的根治靠「参数隔离 + 外部化」，不是靠反复训权重——这正是我们「用户记忆空间独立于主干、可增删不动物主一个参数」第一原则的学术背书。
