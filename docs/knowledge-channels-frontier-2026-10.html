非预训练知识摄入通道 · 前沿调研

报告日期：2026-10-17 ｜ 检索窗口：近 6 个月 ｜ 定位：验证「0.5B 后不靠预训练也能继续吃知识」的路线假设
核心结论：用户直觉成立，且已被前沿反复证实。「让模型吃进更多知识」从来不是只有预训练一条通道。2026 年前沿已经跑通另外四条——推理时学习（TTT / fast weights / 记忆层）、工具+检索、自生成数据再训（RSI）、外科手术式知识编辑。预训练只是其中最贵、最慢的一条。对 0.5B 后的融合版模型而言，主通道将从「喂数据重训」切换为「推理时学习 + 工具 + 自进化」。

一、「吃知识」的五条通道全景

通道机制成本即时性前沿代表
① 预训练 / 续训 语料进梯度，改权重 最贵 最慢 我们正在跑的 0.3B→0.5B 扩容链
② 推理时学习
TTT / fast weights		 推理当场用输入自监督更新一小撮权重，不改主干 低 秒级 In-Place TTT（ICLR 2026 Oral）；fast-weight memory；Titans
③ 外置记忆层 知识住可寻址键值库，推理时检索读回，权重冻结 极低 即时 Memory Layers；Titans 神经记忆；我们的 10M 个人记忆三层
④ 工具 + 检索 不碰权重，调用外部知识源/工具现场取 零训练 即时 RAG、MCP 工具、zen-gate 模型池协作
⑤ 自生成数据再训
RSI		 模型自己出题/解题/验证，只留验证正确的再训练 中 轮次级 BigBang-V1；Darwin-180B-RSI；MetaRSI-v1；AIBuildAI PostTrain
关键认知：五条通道不是替代关系而是分层关系——预训练打地基（参数容量），推理时学习做现场适配（激活容量），外置记忆做个人知识（可删容量），工具做无限外延（不占容量），RSI 做闭环增长（自己造容量）。0.5B 后的模型形态 = 「小主干 + 强外挂」。

二、四个最关键的发现

1. In-Place Test-Time Training ICLR 2026 Oral

arXiv 2604.06169 · 2026-04
  • 把 Transformer 中本来就存在的 MLP 末端投影矩阵当「fast weights」，推理时更新——不新增任何组件，drop-in 可用，无需重训。
  • 4B 模型在 128k 上下文上超过更大模型；计算与内存开销可忽略。
  • 理论炸弹：数学证明了此前五年 TTT 方法优化的目标函数对语言建模「期望效果可忽略」——旧路线建立在错误目标上，换成与 next-token prediction 对齐的目标后才真正生效。

2. Learning, Fast and Slow 反直觉

Databricks / UC Berkeley · arXiv 2605.12484 · 2026-05
  • fast weights = 优化过的文本 prompt（吸收任务知识）；slow weights = 锚定在基座附近的参数（少动、慎动）。3× 样本效率，同性能下 drift 减少 70%。
  • 重磅发现：纯 RL 训练会让模型「越学越僵」——权重离基座太远后，注入新任务信息直接崩溃；fast-slow 框架的模型则能继续学第二个任务。
  • 这与我们的路线直接同构：主干锚定保函数 + 外置适配层吸收新知识，正是 fast-slow 的工程化表述。

3. fast-weight memory：纯前向装新规则

独立研究员 · 2026-07 · r/LocalLLaMA 热度验证
  • 300 万参数小 Transformer，仅前向传播（无反传、无传统 TTT）即在推理时「安装」从未训练过的规则，并泛化到新样本。
  • 实测比测试时训练和上下文学习更高效——单块 RTX 3090 完全可复现。
  • 意义：推理时学习的成本下限被压到「一次前向」，端侧常驻模型现场学新规则成为可部署选项。

4. mdlARC：小模型 + TTT 反杀 成本断档

75M 参数 · ARC-AGI-1 公开集 44% · 总成本 $0.67 / 1.5 小时
  • 每道题现场从随机初始化训练（test-time training），用题目自带示例对归纳规则，测试标签严格隐藏。
  • 同等准确率下成本是 TRM 的 1/240（$0.67 vs $158）；架构组件（3D RoPE、per-task embedding）消融后从 44% 掉到 24%。
  • 意义：「规模碾压」不是唯一解——小模型 + 测试时学习 + 好表征设计，在低数据抽象推理上匹敌专为 ARC 设计的循环架构。直接支撑「小模型走到极致」的战略。

四、对我们路线的三个直接冲击

冲击 1：E-7 宪法被前沿佐证，且是唯一解

  • Titans / Memory Layers 路线 = 知识住神经记忆或键值库，主干权重冻结；我们的「个人数据只进可寻址可删除记忆层、绝不进参数」不是保守，是与前沿同代的设计。
  • fast-slow 论文的发现（RL 让模型僵化）进一步支持：主干少动、外置层多动是能力增长与可删除性的共同解。

冲击 2：算力约束下，TTT 比预训练便宜一个数量级

  • node1 实测：容器仅 8 核、主链训练占 7.9 核，纯 CPU 任务被卡到 0.12 核——预训练扩容在免费 CPU 上是奢侈品。
  • 推理时学习只更新一小撮权重（adapter / 投影矩阵 / 记忆槽），算力需求低 1–2 个数量级，本机都能跑（识图对齐已验证：0.78M 投影层本机训练毫无压力）。
  • 结论：0.5B 后「继续吃知识」的主战场从 node1 预训练，转移到端侧推理时学习 + 外置记忆——这恰好也是融合版的部署形态。

冲击 3：mdlARC 式「小模型 + 现场学习」是 B 线的终极形态

  • 小模型 + 测试时学习 + 脚本验收 = 我们的「模型做 executor、脚本+多模型评委做 verifier、人只目检最终结果」。
  • Timeline-Bench（最强 agent 仅 26.8%、72.9% 败在质量非合规）说明瓶颈在验证不在规模；mdlARC 说明验证到位时小模型能反杀。两条拼起来 = B 线的实证地基。

五、落到 0.5B 融合版：「吃知识」的具体形态

预训练收尾→ 推理时学习（fast weights / 记忆槽）→ 外置记忆层（10M 个人空间）→ 工具 + 检索→ RSI 闭环（代码层→数据层→权重层）

一句话：参数 0.5B 封顶不是终点而是起点——从「喂出来的智能」切换为「长出来的智能」。前端四条通道全部零/低训练成本，与端侧常驻、BitNet 三值、看门狗共同构成融合版；RSI 是唯一需要回到训练管线的通道，且只消化「自己验证过的数据」。
