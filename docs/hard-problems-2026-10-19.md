# 北极星项目｜六道前沿难题（给 GPT-5 / Claude 5.5 级模型）

> 使用方式：**一次只问一道**。六道一起贴，模型会给六份泛泛而谈；单问一道，它才会真的推演。
> 每道题末尾都写了「可证伪的判定」，答完必须能落到一个能跑的实验上，否则就是空话。

---

## 项目背景（对方只需要知道这些）

在纯 CPU 上从零预训练一个中文小模型，代号北极星。当前主干 `polaris-03b`：

| 项 | 值 |
|---|---|
| 参数量 | 346.9M |
| 层数 / hidden | 36 / 576 |
| 词表 | 49152（自建，含 `<\|im_start\|>`=1、`<\|im_end\|>`=2） |
| 纯文本 NLL 实测 | **2.505 ~ 2.664**（PPL 12~14），chat 模板 3.735 |
| 训练环境 | 8 核 CPU（burstable，实测有效 3~4 核），无 GPU |

设计约束（视为公理，不要建议推翻）：模型要能在本地 CPU 上长期自进化，个人数据**不得进入被训练参数**，只能进可寻址、可逐条删除的外部记忆层。

## Q1｜346M 冻结主干上，音频接入的 prefix 范式是否根本不成立？

**事实**

- 音频：AISHELL 中文，5464 条训练 / 584 条验证（验证集是两个**未见说话人** S0018、S0019）
- 特征：whisper-small encoder，768 维，1500 帧，池化到 150 帧后缓存
- 接入方式（early fusion）：`[150 个音频 soft token] + [28 prompt token] + [23 目标 token]`，序列长 219
- 可训练参数：**只有一个 2 层 MLP（768→576→576），0.78M**，主干 36 层全部冻结
- 训练：800 个 optimizer step × accum 4 = 3200 条样本 = **0.59 个 epoch**，lr 3e-4，AdamW，grad clip 1.0
- 结果：盲测 **CER 7.422，中位 4.0，10 题全错**；10 条里有 **6 条输出完全相同的句子**「与其他高校的学生之间的联系起来」
- 真实 loss 曲线：3.80 → 3.62（800 步只降 0.18，此前因为显示 bug 被误读成 14）

**已经逐一实测排除的**

| 假设 | 实测 |
|---|---|
| 梯度消失 | 梯度 norm = 85 / 12.7 / 37，四个参数块全有梯度 |
| 底座坏了 | 纯文本 NLL 2.5（PPL 12~14），词表与特殊 token 全部对齐 |
| 音频特征塌缩 | 不同音频两两余弦 mean 0.864（min 0.80 / max 0.94），有区分度 |
| prefix 太长 | 同一随机 projector 下：1 token loss 3.802 → 150 token 3.839，**几乎无差** |
| 投影输出尺度过大 | 输出 norm 39.9 vs embedding 行 norm 2.978（13.4 倍），但 RMSNorm 逐 token 归一化后尺度不再有影响 |

**要你回答的**

1. 在「主干冻结 + 0.78M 可训练参数 + 346.9M 容量 + hidden 576 + 36 层」这个约束下，**prefix soft token 是不是错误的范式**？如果是，错在容量的哪一环（浅层表示能力 / 注意力头的多样性 / 残差流的信息带宽）？
2. 给出替代方案的**优先级排序**并说明样本效率依据：跨层 cross-attention adapter、在中间层做 gated 注入、CTC 辅助目标 + 文本蒸馏、只学「音频→伪文本」再由主干复述、其他。
3. 关键约束：单样本前向+反向 1.7 秒，**总预算 20 小时 CPU**（约 42000 个样本梯度）。在这个预算内，哪条路最有可能把 CER 从 7.4 降到 1.0 以下？

**可证伪的判定**：给出一个能在 20 小时预算内跑完的最小实验，明确「如果指标 X 在 N 步内不越过 Y，则该范式判死」。

## Q2｜「格式能教、内容教不了」这个二分，是否真的不可破？

**事实**

在 45 道自建代码题上的实测（0.3B 挂编程 LoRA，只挂 q/k/v/o）：

- 裸 `polaris-03b`：strict 通过 **0/4**，代码块出现率 **0%**
- 裸 `Qwen2.5-0.5B`（同参数规模）：strict **2/4**，代码块 **100%**
- 0.3B 自产代码跑满 45 题：**ACCEPT 9 / REJECT 25 ≈ 26%**
- 进一步分层：把「模板化能解」的题型叫波类，**波类存活率 99%**；非波类 **37.7%**，而其中 **62.3% 是 `sin` 套壳**（把题目硬套进已知模板）
- 质量银行：三元组 201 → 210 条

由此得出目前的核心判断：**内容层（代码对不对）由底座决定，模块只能教格式层（吐不吐代码块、有没有语言标注、收没收尾）。**

**要你回答的**

1. 这个二分在原理上是否严格？换句话说，「表征里有没有代码能力」和「能不能按协议输出」之间，是否真的存在一条干净的界线，还是当底座足够小时两者会互相锁死（连格式都学不会就是因为内容层缺失）？
2. 如果二分不严格，**有没有第三条路**——不把代码能力放进参数，而是把它变成「可检索片段的条件组装」？在 346M 的底座上，这种「检索 + 组装」能做到什么水平？pass@1 的天花板在哪里？
3. 已知 Qwen2.5-0.5B 同规模就有代码能力，说明 346M 并非容量下限。那么 **`polaris-03b` 缺的到底是「代码语料」（数据问题）还是「代码表征的可分性」（预训练目标问题）**？给出能区分这两者的实验。

**可证伪的判定**：给出一个实验，其结果能明确回答「内容层是否可以在不重新预训练的前提下被补上」。

## Q3｜跨血统迁移：词表不同是否构成绝对壁垒？

**事实**

模块（LoRA / adapter）跨底座移植的三组实测：

| 场景 | 结果 |
|---|---|
| **同血统**（自家 0.2B → 0.3B，跨代 + 跨 intermediate size，只加层） | ✅ **成立**。零填充重映射后 `max\|logits diff\| = 0.000e+00`，行为复现（两代都吐「好，主人。」） |
| **同架构不同血统**（SmolLM2-200M） | 🟡 **一半**。从复读机变成会说话，但身份与内容全错 |
| **跨血统**（Qwen2.5-0.5B，不同词表 + 不同 hidden） | ❌ **不成立且有害**。完全无「主人」概念，某些情况下比裸模型更差，还会编造虚假身份 |

结论：模块的可移植性边界 = 预训练血统的边界。跨血统只能带走数据、方法、验收标准。

**要你回答的**

1. 「不同词表」是否构成**绝对壁垒**，还是在特定条件下可被投影掉？请分别评估三条路在**学生模型只有 346M** 的前提下的可行性，并给出排序：
   - (a) 共享子词表投影：把 teacher 与 student 的词表求交集，用交集上的 embedding 拟合一个线性/低秩映射
   - (b) 激活空间对齐：用 CKA / Procrustes 在逐层激活上对齐，再把 teacher 的 adapter 变换到 student 空间
   - (c) 行为蒸馏：完全不管权重，只用 teacher 的输出分布训 student
2. 三组实测里，「同架构不同血统」停在 🟡（会说话但内容全错）——这更可能卡在**词表不对齐**还是**预训练分布差异**？给一个能分辨两者的诊断实验。
3. 是否存在「词表无关的能力载体」这种概念？如果存在，它在哪一层（残差流方向？注意力模式？），怎么读取？

**可证伪的判定**：设计一个实验，在 Qwen2.5-0.5B 上训一个模块，迁移到 polaris-03b 时行为保持率超过 50%（当前接近 0）。

## Q4｜零填充扩容后，新容量的「激活条件」是什么？

**事实**

为了让模型能在不破坏已有函数的前提下长大，采用**保函数扩容**：

- 只做两种操作：MLP 加宽（`intermediate_size` 增大）、零输出恒等层插入（新增层输出恒为 0）
- 硬契约：模块**只允许接恒定维**（`q/k/v/o_proj`、残差流 adapter），**禁止接可扩维**（`gate/up/down_proj`），否则每次扩容都要重映射，扩不宽就作废
- 实测：0.2B → 0.3B → 0.4B 三次扩容，旧子空间逐位相等，`max|logits diff| = 0.000e+00`
- 0.4B 是 42 层 vs 0.3B 36 层，多出来的 6 个 MLP 末端被规划为 In-Place TTT 的「可写秩」（+6×576 个方向）

**核心矛盾**：零输出恒等层的初始贡献**恰好为 0**。这意味着扩容本身不改变任何输出，但也意味着**没有梯度信号告诉新增容量该学什么**。

**要你回答的**

1. 在 function-preserving expansion 之后，新增容量的「唤醒」机制应该是什么？是由下游 loss 自然传播，还是需要显式的辅助目标（如让新层的输出逼近某个 teacher 层的残差）？
2. 已知约束是「不能重新预训练」（算力不够）。在只有**继续训练现有语料**的情况下，新容量会不会永远保持接近 0 的输出（即扩容白做）？有没有实测过的反例？
3. 「容量」在这个语境下是否可能根本不等于「参数量」——比如有效秩、残差流的通道多样性才是真容量？如果是，那加宽 MLP 和插入零输出层哪个更有效？

**可证伪的判定**：给出一个判定「新增容量是否真的被用起来」的可测量指标（不是参数量、不是 loss），并说明阈值。

## Q5｜「个人数据不进参数」如何被**证明**而不是被**声称**？

**事实**

项目宪法里有一条硬约束（编号 E-7）：**个人数据绝不进入被训练参数，只能进入可寻址、可逐条删除的记忆层。**

现状实现：

- 记忆层 = TinyContext（SQLite + FTS5 + sqlite-vec），每条记忆可单独删除
- 训练用的语料已经过清洗，理论上不含个人信息
- 但**没有任何机制能证明参数里没有**

这不是学术洁癖。如果做不到可验证，整个「本地自进化」路线就有一个无法向用户交代的漏洞：模型权重是不可逆的，一旦某条个人信息进了参数，删除是不可能的。

**要你回答的**

1. 在「无法访问原始预训练数据、只能访问最终 checkpoint」的条件下，有哪些方法能对「某条特定信息是否在参数里」给出**可操作的证据**？membership inference attack 够不够？它的检测下限（多长的信息、多少重复次数才能被检出）是多少？
2. 更根本的问题：是否存在一种**架构级**的做法，让「参数里没有个人信息」成为结构性事实而不是经验性观察？比如把所有涉及个人的通路都做成外部可寻址查表（类似 product key memory），参数只学「怎么查」不学「查到了什么」？
3. 如果架构级方案代价太大，退一步：能否设计一个**训练期审计**——在每次微调后自动跑一组「该记住的不该忘 / 不该记住的不许出现」的对照测试，把违反率作为发布门槛？这种审计的假阴性率大概什么量级？

**可证伪的判定**：给出一个能在单机 CPU 上运行的审计流程，对一条植入的个人信息给出「在/不在」的判定，并标明该判定的置信度。

## Q6｜In-Place TTT 的稳定性条件与遗忘边界

**事实**

采用的推理时学习方案（In-Place TTT）：

- fast weights 落在 **MLP 末端的 `down_proj`**，纯前向更新，**不走反向传播**
- 更新规则：每 k 个 chunk 做 k 次 **rank-1 外积**，等价于让该层有效秩 **+k**
- 规划：0.4B 的 42 层比 0.3B 的 36 层多 6 个 MLP 末端，即 TTT 可写秩总量 +6×576 个方向
- 现状：163 行 harness，只在 0.2B 上跑过「装知识前后」的演示，未做稳定性验证
- 已知坑：旧版 TTT 的目标函数在这种结构上失效，必须改成 next-token 对齐

**要你回答的**

1. rank-1 外积**累积**会不会饱和？如果每 k 个 chunk 都加 k 个方向，长期运行（比如连续处理 10 万条样本）后 `down_proj` 的谱会怎么演化？会不会出现「新知识写不进去」（已满秩）或「旧知识被挤掉」？
2. 纯前向更新的遗忘边界在哪里？有没有一个可计算的量（比如权重更新的累积 Frobenius 范数占比、或者谱范数的漂移量），能在**污染主干之前**触发回滚？
3. 「只更新 MLP 末端」这个设计，理论上能承载多少新知识？是受限于该层的秩，还是受限于它输出被后续层如何消费？如果 42 层各写 576 个方向，总量够不够装下一个领域的知识（比如 10 万条三元组）？
4. 由于是纯前向，如何保证 next-token 对齐的目标函数在前向模式下仍然成立？给出具体的损失形式。

**可证伪的判定**：给出一个长期运行（≥1 万条样本）的稳定性指标与回滚阈值，且该指标必须能在 CPU 上实时计算。
