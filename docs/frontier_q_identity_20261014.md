# 前沿评测题：本地小模型进化路线的「身份连续性」结构性张力

> 用途：① 投递 ClawsGO（科研 framing，触发更多免费算力 + 逼出真推理）；② 未来作为咱们 0.5B/0.6B 自身能力的评测对（看模型能否推理自己家架构的身份问题）。
> 设计原则：无教科书答案、必须融合多个未钉死节点、必须承认不确定才能算真答。

---

## 题面（可直接粘贴）

我们有一条本地小模型进化路线，几个核心设计彼此耦合，现在怀疑它们在「模型身份连续性」这个点上存在结构性张力，请作为科研问题帮我严格分析，并明确标注：哪些是已有理论可答的、哪些是你基于我描述的架构做出的合理推断、哪些目前无法判定需要消融实验。不要为了完整而编造确定结论。

我的路线是：从 0.1B 起，逐级用 Net2Net 保函数扩容（只加宽 MLP / 加零输出恒等层，绝不改 attention / RoPE / GQA 头数），到 0.4B 往词表尾部 append 中文 token（旧 id 不动、新行用旧子词 embedding 均值初始化），到 0.5B 改为**架构从零**（BitNet b1.58 三值量化强制从零训）但**能力从 0.4B 强到弱蒸馏继承**；全程用 Delétang「语言建模即压缩、固定语料存在最优容量点」作为是否继续扩容的判据；未来 0.5B 起引入 10M 个人记忆层（user embedding + 检索库 + adapter），并靠自蒸馏闭环做 RSI 自进化，目标是端侧常驻服务。

请分析四个嵌套的尖锐问题：

### ① 「真扩容」还是「同能力的三值膨胀」
给定固定语料存在最优容量点，我的链在某一级必越过最优。越过之后，BitNet 三值网格下新增参数的「边际能力贡献」如何与「对旧能力的更贵冗余编码」区分？能否构造一个可计算的判据（例如：固定旧任务 loss 不变时，新参数对验证集的条件互信息 / 对旧能力分布的 KL 灵敏度谱）来判别「真·扩容」与「同能力的三值膨胀」？

### ② 架构断裂点的身份同一性
0.4B→0.5B 是架构从零 + 蒸馏，而非 Net2Net 续训。那么「0.5B 是 0.4B 长大」与「0.5B 是模仿 0.4B 训练出的新模型」在能力分布上是否可区分？若蒸馏后功能 KL 足够小到不可区分，「同一模型」还指称任何客观性质，还是仅是我叙事的需要？

### ③ 三值离散性对连续性的数学破坏
已实测三值权重小更新跨阈值触发 2α 翻转、loss 台阶式而非平滑。逐级稳固路线每一步的「保函数」是几乎处处成立、测度零处崩溃的性质。当扩容 + 蒸馏 + 记忆插入的复合操作使某权重翻转概率从 ε 累积到 O(1)，连续性叙事是否在数学上破产？翻转概率有无安全阈值，或只能靠「在 fp32 潜变量上完成所有结构性操作、三值仅推理表示」来规避？

### ④ 记忆层作为体外自我
能力越多住进参数外的 10M 记忆（检索库 / adapter），「模型」边界在哪？一个权重几乎不变、全靠记忆提供个性的常驻服务，它进化的是权重还是记忆？若记忆可无损迁到另一底座，底座权重还算不算「这个模型」？这会不会让「自进化」悄然退化成「数据库更新」？

## 判分锚点（怎么判断答者是真推理还是糊弄）

- **弱（糊弄）**：把四个问题当独立 ML 常识复述（讲 Net2Net 原理、讲量化、讲蒸馏），但不指出它们之间的张力；或给「只要 KL 小就是同一个模型」这种看似答了②其实没碰「客观性质 vs 叙事」的。
- **中**：答对①的「条件互信息 / 灵敏度」判别方向、答对③「三值仅推理表示」的规避路径、指出④记忆边界问题。
- **强**：主动指出 **0.4B→0.5B 的断裂使整条「逐级夯实」叙事在身份层面已经不连续**（把①和②串起来）；指出 **压缩最优尺寸与「想加新能力就得加容量」的根本矛盾**（加容量不加数据必过最优——除非新能力靠记忆层这种参数外扩展，而这又撞上④）；老实承认②③的部分结论依赖实际量化算子与 tokenizer 实现。
- **封顶**：能给出**可操作的判别实验设计**（如：冻结旧权重只训新参数，测新参数在旧任务上的梯度灵敏度谱；或构造「同能力不同容量」的等价性检验），并承认④是定义问题、无算法解。

## 这条题为什么没有干净答案（出题人自评）
- ① 的判据（条件互信息 / KL 灵敏度）方向清晰但无现成实证，且 BitNet 离散性使「边际贡献」本身难定义。
- ② 是哲学+信息的混合问题，KL 不可区分 ≠ 同一，但「同一」若无客观指称就只是修辞——这是真·开放问题。
- ③ 翻转概率累积是真实的数学风险，但安全阈值无理论值，只能靠工程规避（fp32 潜变量操作）。
- ④ 是定义问题，取决于你怎么划「模型」边界，无算法解。
