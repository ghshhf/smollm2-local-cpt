# 双轨殊途同归战略（Two-Track Convergence）

> 定调：2026-10-18 00:15，用户（主人）口述，本会话整理入宪候选
> 一句话：**远程买"参数容量"，本地买"结构能力"，两轨正交可加，在 0.5B 处合流。**

---

## 一、为什么必须分两轨

本地机器（i5-12450H / 16GB / 核显）**没有预训练的容量**：跑不动 0.1B→0.5B 的语料规模，硬跑只是浪费时间。所以这条必须外包给远程 node1（魔搭 64 核报 8 核实）。

但如果本地只做"等远程结果"，那本地就退化成一个下载器——浪费掉本地唯一的结构性优势：**可以反复试错、可以插模块、可以推理时学习**。远程一条大管道跑到黑，改一次要几小时起步；本地一条命令 2 分钟就能验证一个想法。

所以分轨不是妥协，是**各自做自己唯一能做且成本最低的事**：

| | A 轨：远程 node1 | B 轨：本地 |
|---|---|---|
| 扩容维度 | **参数维度**（0.1B→0.2B→0.3B→0.4B→0.5B） | **结构维度**（模块 + 推理时学习 + 外置记忆） |
| 手段 | 续预训练（吃语料） | 模块插入、TTT fast weights、三元组银行、工具 |
| 买到的东西 | 先验密度、语言底座、世界知识的"底噪" | 可组合能力、可删除记忆、秒级装知识 |
| 单次迭代成本 | 天级（R6 一天多，R7 实测更慢） | 分钟~小时级 |
| 不可做的 | 快速试错、私有数据（E-7） | 大规模预训练 |
| 宪法约束 | 保函数扩容（不改注意力维/隐藏维/GQA/RoPE） | 不动主干权重，只动可弃层与外置层 |

## 二、合流点：0.5B

远程到 0.5B 时，本地这条线不是被替换，而是**往上挂**：

```
        远程 A 轨                          本地 B 轨
   0.1B → 0.2B → 0.3B → 0.4B → 0.5B    ┌─ 识图模块（SigLIP2 92.9M + 投影 0.78M）
   （预训练，买容量）                     ├─ 听觉模块（Whisper 编码器 + 投影）
                                        ├─ 记忆层（可寻址、可逐条删除）
         ↓ 合流 @ 0.5B ↓                 ├─ TTT fast weights（推理时装知识）
   ┌──────────────────────────┐         ├─ 工具/检索（零训练）
   │  0.5B 主干（远程归来）      │ ←────── ─┤  模块全部原样插回
   └──────────────────────────┘         └─ 行为技能（编程/爬虫/剪辑）
```

**"殊途同归"的精确含义**：两条路最终描述的是同一个模型——一个 0.5B 的主干，外挂一堆模块，能推理时自进化。远程贡献主干的"厚"，本地贡献外围的"活"。

## 三、⚠️ 合流能成立的唯一前提：模块接口契约

这是本文档**唯一的硬性工程约束**。合流不是免费的，成本大小取决于现在怎么做。

**规则（现在就要开始执行）**：
0. 🔴 **模块只允许接在「恒定维」上，禁止接在「可扩维」上**（2026-10-18 04:05 实测后新增，优先级最高）。
   - 可扩维 = `intermediate_size`（MLP 宽）。0.2B 3072 → 0.3B 4608，接在这里的模块**必破**。
   - 恒定维 = `hidden_size`（576，宪法禁改）、`kv_dim`（192 = 3×64，宪法禁改 GQA）。
   - ⇒ **允许的接入点**：`q_proj / k_proj / v_proj / o_proj` 与**残差流 adapter**；**禁止**：`gate_proj / up_proj / down_proj`。
   - 实测依据：0.2B→0.3B 的 LoRA 共 420 个张量，**330 个（78.6%）零修改通过，全部是注意力模块**；仅 90 个（MLP 宽维）需改。
1. 所有模块**不得硬编码主干维度**。主干 `hidden_size` 必须是配置项，不是常量。
2. 模块与主干之间**只允许通过"投影/适配器"连接**，不允许直接改主干 shape。
3. 每个模块必须自带 `interface.json`，声明它依赖哪些主干属性（hidden / 层数 / 词表），并标注**接入点维度类型**（恒定 / 可扩）。
4. 跨代搬运一律走**零填充重映射**，不走"直接加载"：保函数校验 `max|diff| = 0.000e+00`（已实测）。新增维度贡献恰为 0，旧子空间逐位相等。

**成本模型**（合流时）：

| 场景 | 合流成本 |
|---|---|
| 遵守契约（挂 hidden 维） | 主干一换，**零填充即装，短程微调重定位**（小时级），主干权重一行不动 |
| 违反契约（挂 inter 维） | 每次加宽都要零填充重映射 + 重训（见图），扩不宽就作废 |

**实测得到的两个关键事实**（`tools/module_port_test.py`，2026-10-18）：

| 事实 | 数字 | 含义 |
|---|---|---|
| 零填充保函数 | 旧子空间 `max\|diff\| = 0.000e+00` | 移植是**精确**的，不是近似，与 Net2Net 同一原理 |
| 表示漂移 | cos(0.2B, 0.3B) 残差流：0% 层 0.9986｜25% 0.9375｜50% 0.9085｜75% **0.6263**｜100% 0.9263 | 同血统主干残差基**基本连续**，中层 0.91~0.94；只有 ~75% 深度分歧大 |
| 端到端有效性 | 0.3B 裸：主人 0 次 / 复读 0.36；0.3B+移植 LoRA（未重训）：**主人 2 次 / 复读 0.27** | **部分迁移成功**：身份概念过、精确协议补偿失配 |

⇒ **因此合流时"模块原样插回"要读作"零填充插回 + 短程微调"，不是"一字不改直接用"。** 前者小时级，后者不存在。

🔴 **一个被反复误传的点**：0.5B 主干 `hidden` **不会变大**。深度优先扩容只加层，`hidden=576`、`inter=4608` 全程冻结，所以注意力模块从 0.3B 起**永久有效**；需要重训的只是"新增那几层没有模块"和"表示漂移要重新定位"，两者都不是接口问题。

## 四、论文/前沿与两轨的映射（昨天让你看那些论文的真正原因）

| 前沿成果 | 归属轨 | 在我们体系里的位置 |
|---|---|---|
| **In-Place TTT**（ByteDance-Seed, ICLR2026 Oral, arXiv 2604.06169） | **B 轨核心** | 推理时学习的落地mechanism：把知识装进各 MLP 末端 `down_proj` 当 fast weights，**纯前向 chunk 累积外积更新，无反传无优化器**。SmolLM2 是 Llama 架构，原生支持，有零额外参数变体。这是本地能跑、远程不需要的东西。 |
| **mdlARC**（75M + TTT 打 ARC 44%，成本 $0.67 反杀大模型） | B 轨证据 | 小模型 + 推理时学习能在特定任务上超越大模型——B 轨不是"退而求其次"，是另一条能赢的路。 |
| **VisionPsy-Nano**（SigLIP2 + SmolLM2-360M，sub-0.5B 榜首） | B 轨蓝本 | 与我们的基座**同源**的现成验证：视觉能力是插件不是主干属性。 |
| **LLaVA 665K 实证**（质量 > 数量） | B 轨数据原则 | align 阶段用干净单一分布（纯 COCO），不混 OOD。 |
| **Knowledge Seeding**（Google 2606.03979，小 self → 大 self 向上蒸馏） | **合流机制** | 远程 0.5B 归来后向下/横向迁移的参考范式。 |
| **Metis**（记忆层 mid-training，arXiv 2607.26760） | B 轨（部分采纳） | 借鉴记忆目标与 memory attention；**潜状态压缩不满足 E-7（不可逐条删除），不照搬**。 |
| **Safe Inheritance**（自进化 14% 回归到基线以下） | 治理 | **必须留强 rollback**（v5 目录保留就是这个原则）。 |
| **Circularity**（solver 与 evaluator 不可同环进化） | 治理 | 验收标准由人定，训练环改不了（v6 盲测标准人类设定）。 |
| **L2 信息天花板**（固定语料加 epoch 收益递减） | B 轨止损 | v6 的 3000 步是**诊断上限**，不过就转查数据/容量，不在 0.2B 上死磕。 |
| **Fast-Slow 论文**（纯 RL 让模型越学越僵） | 佐证 | 主干锚定 + 外置适配的路线是对的。 |

## 五、止损与风险治理

1. **A 轨风险：远程变慢即事实停滞**（当前正在发生，见下节）。判据不是"心跳在不在"，是 `tok/s` 和 `done_steps` 有没有动。
2. **B 轨风险：加 epoch 不涨** → 立刻转查数据/容量，不继续堆（L2 天花板）。
3. **合流风险：主干换轨导致模块失效** → 用接口契约压到"只重训适配器"。
4. **E-7 铁律不变**：个人数据绝不进被训练参数，只进可寻址可删的记忆层。B 轨的记忆层/TTT 都必须满足可弃性（fast weights 推理时可弃）。
