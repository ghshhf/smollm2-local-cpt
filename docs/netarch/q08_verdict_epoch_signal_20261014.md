# Q-08 交叉裁决：单遍 vs 多 epoch 的训练时在线判据（矛盾7 文献空白）

> 2026-10-14 · 多模型独立交叉（gemini-3.8-flash / nemotron-3-ultra / north-mini-code 等）· 原始答案 `fleet_answers/Q-08/`
> 这道题问的是矛盾7：我们 0.1B–0.4B 默认单遍，但"什么时候单遍不够、该二刷"没有实时判据。**本题有强趋同答案。**

## 一、🔴 强趋同结论（gemini + nemotron 独立收敛）

**两家独立收敛到同一个信号：梯度的方向一致性（梯度余弦相似度）。**

| 维度 | gemini (CMA) | nemotron (TGCSM) | 裁决 |
|---|---|---|---|
| 核心信号 | `cos(g_t, m_{t-1})` 当前梯度 vs **AdamW一阶动量** | `cos(g_t, g_{t-1})` 当前梯度 vs **上一梯度**，token-wise 均值 | **本质同一：梯度方向一致性**。动量是梯度的历史平滑，两者数学同源 |
| 泛化期特征 | A_t>0（通常 +0.15~+0.40），梯度与历史方向高度重合 | cos 上升，不同 token 梯度指向一致低维子空间 | **一致：泛化=梯度方向一致** |
| 记忆期特征 | A_t→0（独立随机向量几乎必然正交），甚至转负 | cos→0 或负值，梯度指向正交/随机 | **一致：记忆=梯度趋正交/对抗** |
| 为什么不用其他候选 | 参数漂移率=滞后指标抓不到相变；单样本 loss 方差随语料漂移；loss 曲率 CPU 信噪比太低 | GSNR 需存全梯度历史、超显存；参数漂移无法区分"有效压缩"与"死记" | **一致排除：参数漂移率、单样本方差、loss 曲率** |

**机制（两家共识）**：
- 泛化期 = 流形对齐/压缩未见模式 → 不同 batch 梯度指向共享结构特征，方向**共识**；
- 记忆期 = 拟合单 batch 表面残差 → 梯度只为本 batch 独有特征服务，方向**正交甚至对抗**。

## 二、采纳的判据（双门限状态机，gemini 最完整）

基于 EMA 窗口 W=50 的 `EMA(A_t)`，以 epoch1 末期滑动平均 `Ā_ep1` 为基线锚定：

1. **弱泛化区判定**：`EMA(A_t) < 0.3 × Ā_ep1` → 进入警戒，泛化增益已近饱和。
2. **硬停判据（立即 Early Stop）**：`EMA(A_t) ≤ 0.02` **且** `P(A_t ≤ 0) ≥ 0.45`（窗口内近一半步骤梯度对抗）→ 停止 epoch2、保存模型、严禁继续灌。

## 三、CPU 可行性（关键，gemini 给了硬数字）

- **不需高阶算子、不需单样本梯度（不用 vmap），不增加反向传播 FLOPs**；
- AdamW 步进时 `m_{t-1}` 与 `g_t` 已在内存；只需一次全局内积+范数归约；
- 64 核 AVX-512 上 **1.5~4.5ms/步**，相对 forward+backward ~200~500ms，**开销 < 1%**；
- ⇒ **本机/ node1 CPU 实时算得起**，可作训练内嵌监控。

## 四、它如何喂给 distil_gate / data-plan

- 这给我们 data-plan 八·五 F 补上了一个**训练时实时**的 epoch 判据，与"外部 holdout 事后验证"互补（holdout 是事后、滞后；CMA 是实时、领先）。
- 与 distill_gate 的 JSD 分歧门控同源思想：都靠"分布/方向的偏离"做闸门。
