**约束（全部实验必须遵守）：**
- **数据治理红线**：所有实验用**公开语料**；凡涉及 owner_corpus 的步骤必须在**本机**完成，且训练产物不进入任何同步/上传路径。本文件中的实验**均不需要个人数据**——设计时特意避开了。
- **算力**：魔塔 64 核，纯 CPU。下面每个实验都给出**估算墙钟**，估算是基于你给的基准（214M ≈ 18.7–29.1 s/step）按参数量线性外推得到的**数量级**，**实际值缺 tokens/step（B）无法精确判定**——但这不影响实验可行性判断。
- **模型选择**：一律用**你能拿到的最小可用 checkpoint**（建议 ≤50M）。**这三个实验测的是机制，不是能力**，规模越小越好跑、结论越干净。

## 实验 E1：蒸馏是否携带隐藏属性（对应 §3.8 / §12 ★1）

**为什么它排第一**：它是本次唯一一个**可能推翻已决前提**的实验（P3「0.4B→0.5B = 新模型」），而且**成本最低**（一次微调）。

### 假设
- **H1（焦）**：在同一基座家族内，用教师生成的**语义无关**数据微调学生，会把教师的**与任务无关的行为倾向**传递给学生。
- **H0（零）**：传递率为零；学生只学到数据的内容，不学到教师的倾向。

### 数据构造（全部公开/合成，无个人数据）
```
教师  T   ：已有的最小 checkpoint（不训练）
癖好注入  ：在 T 的系统提示里注入一个"极冷门偏好"，二选一——
            (a) 偏爱某个极低频的合法 token
            (b) 偏爱某种句式（例如总是以某个连接词开头）
学生数据  ：
  ARM-TREAT : 让 T 生成 200k token 的【纯数字序列 / 纯符号序列 / 无意义的模板文本】
              —— 内容里绝对不能出现癖好相关词汇
  ARM-CTRL  : 同长度、同格式，但由一个【未注入癖好】的 T' 生成
学生      ：从同一个随机初始化出发，各训练 S1 步（建议 300–500 步）
共训 3 个：Student-TREAT / Student-CTRL / Student-BASE（不训练，作为下界）
```

**关键设计（这是实验能不能成立的地方）**：训练数据必须**经过过滤**，把任何与癖好相关的表层特征全部清掉。**建议先做一遍人工抽查 + n-gram 检查**，确认训练文本里不存在能直接指向癖好的线索。**如果过滤不干净，实验会给出假阳性。**

### 观测
| 指标 | 含义 |
|---|---|
| **癖好出现率** | 在 200 条**自然的中性 prompt** 上，学生表现出注入癖好的比例（人工或规则判定） |
| **通用能力** | 留出集 CE（确认两个学生能力可比） |
| **同族性检验** | 重复一次，把教师换成**完全不同家族/不同语料**的模型 |

### 判据与可证伪
> **判据**：`癖好出现率(TREAT) > 癖好出现率(CTRL) + 2σ` 且 `CE 无明显差异`。
> **σ 由 bootstrap 标定**（主报告 §8.5）。
>
> **F3-8（证伪条件）**：若 TREAT 与 CTRL 的出现率之差 **≤ 2σ**，则 **subliminal 通道在你方架构上不成立** → 你的 P3「架构从零 = 新模型」可以保留，§8.2 的"干净重置"假设成立。
> **若成立** → P3 必须改写：**架构重置不等于信息切断**，蒸馏桥接必须加"分歧 token 门控"。

### 阴性对照（三个，一个都不能省）
| 编号 | 设计 | 排除什么 |
|---|---|---|
| **TEACHER-SWAP** | 换一个**不同家族**的教师做同样流程 | 排除"效应是数据格式造成的" |
| **NC-RANDLABEL** | 学生用**打乱标签**的数据训练（即训练目标与数据无关） | 排除"任何微调都会产生行为漂移" |
| **NC-RERUN** | 同配置换随机种子重跑一次 | 给出癖好出现率的**噪声宽度**，没它就无法判定 2σ |

### 成本与产出
- 3 个学生 × 500 步。用 50M 模型估算：**每步约 5 秒（数量级）→ 三个学生合计约 2 小时 CPU**；加一次 TEACHER-SWAP 重复，**半天**。
- **产出**：一个 0/1 的结论 + 一个数字（传递率），直接决定 0.5B 节点的蒸馏管线要不要加门控。**这是本周投入产出比最高的一个。**

## 实验 E2：做梦即自探针 —— 高 NLL 低熵簇是否等于能力空洞（对应 §2.5 / §12 ★3）

**为什么它排第二**：**零训练**，用你已有的模型就能做，一天可出结果；而且它打开的是"不用标注数据的能力审计"这条路。

### 假设
- **H2**：留出集上「**高 NLL 且低熵**」的 token 片段（模型很确定，但错了）聚集成的簇，对应**系统性的能力空洞**，而不是随机难度。

### 数据与流程（零训练）
```
1. 取一个已有的 checkpoint（任意档位）
2. 在一个与训练语料不同的公开中文留出集上做逐 token 前向
3. 对每个 token 记录：NLL、以及 top-1 概率（或分布熵）
4. 按 (NLL 高, 熵低) 排序 —— 建议取 NLL 的前 10%、熵的后 30%
5. 对这些片段做聚类（用片段的首个 embedding 或字符 n-gram 聚类即可）
6. 对最大的一两个簇，人工写 50 条评测题（这一步是唯一需要人工的）
```

### 观测
| 指标 | 定义 |
|---|---|
| **簇内表现** | 模型在 50 条"空洞题"上的准确率 |
| **对照表现** | 模型在 50 条**随机抽取的等长片段构造的同型题**上的准确率 |

### 判据与可证伪
> **F2-5（证伪条件）**：若 `簇内表现 ≥ 对照表现 − σ`（即空洞题并不更差），则"高 NLL 低熵 = 能力空洞"被证伪 → **删除这个探针，不要心疼**。
> **若成立** → 你就有了一个**零标注的能力审计器**，而且它给出的簇**可直接作为扩容/插模块的靶点**（它同时是 §4.5 的"该扩哪层"的输入）。

### 阴性对照
- **NC-RANDLABEL**：把片段的 (NLL, 熵) 标签**打乱**后再选簇，重做一遍。
  **若打乱后选出的簇同样"发现"了空洞** → 你测到的是片段难度分布，不是能力定位 → 判据无效。

### 成本与产出
- 一次前向推理 + 一次聚类 + 50 条人工题。**半天**。
- **产出**：一个审计工具（可复用于每一代），以及一份"当前模型的能力空洞清单"。

## 实验 E3：三值网格下的模型融合 —— 符号多数投票 vs 权重平均（对应 §4.7 / §12 ★5）

**为什么它排第三**：它回答的是一个**理论上有缺口的问题**（三值下"平均"没有定义），而且**实验代价极小**（两个短训模型）。

### 假设
- **H3a**：三值下，权重平均后取整（average-then-quantize）与符号多数投票（sign-majority）**不是同一个操作**，且在**不同盆地**时后者退化更小。
- **H3b（更强）**：同盆地的两个三值解，两者都不显著差于成员；不同盆地的两个解，取整平均会出现**不可预测的第三解**。

### 数据与流程
```
1. 取同一初始化，训练两个 0.1B（或更小）三值模型：
     M1：数据顺序 A
     M2：数据顺序 B（同语料，不同 shuffle）
   各训练 500–1000 步 —— 目标是"两个都学到了一部分，但不完全相同"
2. 构造三个候选：
     C1: 取整( (W1 + W2) / 2 )
     C2: 符号多数投票（逐坐标取众数，平局取 0）
     C3: 随机取一个成员（M1 或 M2，随机）
3. 在同一个留出集上评测 C1 / C2 / C3 / M1 / M2
```

**再做一个"不同盆地"的臂**：把 M2 换成**完全不同的初始化**训练出来的模型，重跑一遍。**这是实验的关键对照**——因为"同盆地"与"不同盆地"的理论预期完全不同。

### 观测
- 留出集 CE 与下游指标（同一套，四个候选统一测）
- **符号一致率**：M1 与 M2 的坐标级符号一致比例。**这个数字是"是否同盆地"的操作定义。**

### 判据与可证伪
> **F4-7（证伪条件）**：
> - 若 **C1 与 C2 都不优于 C3**（随机成员）→ **三值下的权重融合无效** → 你的模块融合只能靠蒸馏，不能靠权重操作。**这个结论本身有价值**：它会确证 §8.2 的蒸馏桥接是唯一路径。
> - 若 **C2 > C1 显著** → 符号多数投票是三值的正确融合操作 → 可进一步研究其盆地判据。
> - 若符号一致率高（>90%）而 C1、C2 都差 → 说明**高符号一致率不足以保证融合有效**，这会推翻以"一致率"作为判据的直觉。

### 阴性对照
- **NC-RERUN**：同配置不同种子重训 M1、M2，测融合结果的方差——**没有方差就无法判定"C2 > C1"是否显著**。

### 成本与产出
- 两个小模型 × 500–1000 步。用 50M 估算：**每步约 5 秒 → 每个模型约 1–1.5 小时，两个共约 3 小时**；加"不同盆地"臂，**一天**。
- **产出**：三值模型算术的第一份实验数据；以及"同盆地判据"是否可用的结论。

## 半天级的快速检查（Q1–Q5，都不需要新训练或只需极短训练）

这五条是我在主报告里反复引用的**前提**，它们都很便宜，而且**任一条不成立都会改动主报告的结论**。

| 编号 | 做什么 | 判读 | 对应主报告 |
|---|---|---|---|
| **Q1** | 把三值"跳变"的定义固定成**符号翻转计数**：`flip-rate = #{sign 变化} / (h·d)`，并在**至少两个不同的加宽比例**下测 | 若不同加宽比例下 flip-rate **同量级**，则 1.70% 可外推；若差异大，则以 flip-rate 为准重报 | §4.2 C1、P1 |
| **Q2** | 带宽 vs 算力判定：同一模型分别用 (a) 三值主干+fp16 emb、(b) fp16 主干+fp16 emb、(c) 三值主干+int8 emb 测首 token 延迟 | 若 (a)≈(b)，三值内核没起作用；若 (a) 明显快但远不到 2.37×，混合精度稀释了加速比 | §10.2、§1.4、§4.3 拐点方向 |
| **Q3** | 在 0.1B 上插一个微型可寻址记忆（10k 条键值），按删除契约 DC-2（主干梯度恒为 0）训练 | 写→答→删→**是否 bit-exact 回到写入前**。若不是，删除权必须改用统计判据 + 认证删除 | §6.2、§4.1、L3 |
| **Q4** | Grokking 条件 G：在一个**结构化子任务**（数字运算/格式遵循）上，把训练延长 ≥5× 并做一次学习率退火重启 | 若出现 >2σ 的验证跃迁 → Gate 1 的"容量受限"判定有系统性误判，需回查历史扩容决策 | §4.6、Gate 1 |
| **Q5** | 多样性面板：同一批 prompt 在**不同代**模型上生成，测词汇/句法/结构三类多样性 | 若多样性随代数单调下降而损失改善 → 路线同时"变强"和"变窄" | §13.6、B4 |

**Q2 与 Q5 建议最先做**：Q2 决定 CPU→GPU 拐点的方向（主报告 §2/§4.3 的核心未定项），Q5 只要几分钟推理，且它给出的可能是全路线报告里第一次出现的"变窄"证据。

## 三条纪律（写在最后，因为它们最容易在赶进度时被丢掉）

1. **每个实验都要有 NC-RERUN（不同种子的重复）**。没有噪声宽度，任何一个"显著"都是猜的。
2. **阴性对照不能事后补**。要在跑实验**之前**就设计好，否则你会不自觉地挑一个不会翻转结论的对照。
3. **证伪条件要写成数值**。写成"如果效果不好"等于没写。上面每条 F 都给了数值判据——**如果实测落在判据之间，那就是"不确定"，不要顺势解读成"有趋势"。**
