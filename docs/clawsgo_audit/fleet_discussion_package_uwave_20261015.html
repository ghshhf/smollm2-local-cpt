U1 · V1-01 flip=0 的真实含义 P3 裁决

问：三值探针 flip 恒为 0，是"三值化安全"还是"测量窗口不足 / 未补偿冲击"？
裁决：测量窗口不足 + 退火太快掩盖的假象，不是物理安全。真实翻转需 3000~5000 步 @ lr=1e-4（累积符号翻转率 CFR 才脱离布朗噪声）。
机制：200 步预算内权重位移仅量化步长的 0.004%~0.031%，数学上不可能越过翻转带。静态三值化（α=0）ΔCE 必然 ≥1.8（甚至到随机 3.0+）——这是高维连续流形→三值离散顶点的表征断裂，线性 α 退火越过临界点（≈0.4）发生不可逆相变崩溃，与退火速度无关。提高 lr 到 1e-3 只会让 STE 在阈值两侧极限环震荡、loss 发散。
行动项：0.5B 必须原生 BitNet 从零 QAT，0.4B 当 Teacher 做 logits 蒸馏；绝不在 0.4B fp32 骨架上硬拆换三值。⇒ 与 vision 既定路线一致。P3「架构重置≠信息切断」在本构型下未检出（135M 代理），但 0.4B→0.5B 节点建议更大规模复核一次。

U2 · 压缩准入有效秩判据的自我否定风险 L1 修正

问：L1 用"有效秩变化"做准入判据，会不会自我否定（量化反而抬秩）？
裁决：有效秩 ≠ 信息量，是范畴错误。三值量化引入伪随机高频噪声造成"谱白化"，有效秩被人为抬高——劣质模块反而最容易混过判据。保留 L1，换指标。
修正公式（L1-Fisher 准入）：ΔH_quant = 0.5·Tr(ΔWᵀ F ΔW)/ln2 > N_m·b_eff·ln2。用对角经验 Fisher（128 样本即可），在 CPU 上极低成本预测模块量化至 0.5B BitNet 后的存活能力。Fisher 有效维度才真正反映"量化损伤"，且只修正 L1 的准入损耗，不替代 L1 本身。
行动项：把 execution_manual 的 L1 量化判据从"有效秩"改写为 L1-Fisher；L1 宪法级地位不变。可证伪：在 0.1B 模块上若三值化后有效秩下降>10% 则理论推翻（gemini 给了 <2s 验证脚本）。

U3 · 0.2B embedding 量化决策 精度底线

问：embedding 在 0.2B 是否三值化换带宽？
裁决：严禁三值化。Lookup 每步仅读 1.15KB，带宽占比≈0%；真正吃带宽的是 LM Head 的 GEMV（56.6MB@fp16）。LoRA 式 base_fp16+delta_ternary 是负优化（18bit>16bit）。
三值 embedding 让 Layer0 输入退化为超立方体离散顶点（无求和操作，CLT 失效），容量损失 90.1%，注意力图偏置崩溃；LM Head 三值化还会 Softmax 熵塌缩。折中底线 = INT8（W8A8 / W8A16），训练期保持 fp16/bf16，导出端侧 INT8（仅 ~28MB RAM）；LM Head 可选 ALBERT 低秩分解砍 75% 参数。
行动项：修正"embedding 保 fp16"决策 → 训练 fp16、导出 INT8（精度底线仍在，不冲突）。

U4 · 语料纯度约束的自相矛盾（宪法级） 不降级

问：蒸馏/认主要依赖模型生成数据，与"0.5B 前主干预训练禁模型生成数据"是否矛盾？
裁决：是伪命题。混淆了"数据载体 X（token 支集）"与"监督信号（Teacher soft-logits）"。Gemma2 / Apple AFM 已证实：载体 100% 人写 + 仅 Teacher 软标签监督，即可避免 model collapse。
输入端（主干路径）保留人类语言完整流形；输出端（优化目标）用 Teacher 暗知识压缩梯度方差。自进化/联网学习严格封闭在 L3 外置 10MB 可寻址记忆层（物理隔离、0/1 硬删除），主干权重冻结。这把"纯度"与"脏数据"天然物理隔离。
行动项：宪法约束不降级。"0.5B 前主干加载路径 = 100% 人写 token"为红线；Teacher logits 只算 loss 正则项（绿线），不算生成语料。U4 把 data-plan 八·五·C 的"规则改辞"进一步澄清——不是降级，是区分载体/信号。

U5 · 跨层加宽新层 γ 来源（量化感知 Net2Net） 数学破产

问：三值下 Net2Net 加宽，新层 γ 从哪来才能严格保函数？
裁决：三值严格保函数 Net2Net 在数学上不可能。三值 {-1,0,1} 对除法不封闭；全局耦合标量 γ 使加宽/加深都触发"雪崩式翻转"。Buffer 冻结 γ 破坏 QAT 收敛动力学。
加深：三值恒等矩阵反量化输出被机械衰减 1/d（d=1024 即衰减千倍），无法等于输入。加宽：出射权重需除以 2，但 1/2 ∉ {-1,0,1}；复制神经元改动 γ 后，所有处于量化边界的权重批量翻转（雪崩）。复制式初始化恒等崩溃（误差 >90%）。文献现状：极低比特下唯一可行是"宽蒸馏窄"或"连续空间 Net2Net 后再 QAT"。
行动项：0.1B→0.4B 全程 FP16/BF16 连续空间做 Net2Net 保函数扩容（标量除以 c 严格成立）；0.4B→0.5B 抛弃 Net2Net，原生 BitNet 从零 QAT + 0.4B 蒸馏。严禁从 0.4B 切片拼装三值。⇒ 与 U1 共同锁死 0.5B 路线。
