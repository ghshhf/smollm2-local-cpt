# 🔴 Q1：我实测反驳了外部回答的一半，且给出了正确解释

## 外部回答说"flip rate 该大还是小，你量错了量"

**它说对的部分**：flip 确实是坏指标，单靠它下"崩塌/稳定"结论不可靠。这条对。

**它说错的部分**：它假设 flip=0 是"表示僵死、梯度在错误基底里走"的表现，并归因于**lr 与三值化后梯度尺度失配**（α 调度 vs lr 调度没联合控制）。**这个归因在我实测里不成立。**

## 我实测的根因（硬数据）

flip 的真实定义是**相邻两次测量点之间**的符号变化率（`prev_q` 存上一次的三值符号作比较），不是相对初始量化。所以 flip=0 的含义是"这20 步里没有任何权重的符号翻转"。

量了真实 checkpoint 的权重尺度和量化步长：

```
层                              mean|W|    量化边界带宽   lr=1e-5 下 20 步位移/步长
embed_tokens                0.09728       45.25%              0.010%
layers.0.q_proj            0.18835       35.20%              0.005%
layers.0.k_proj            0.26568       34.03%              0.004%
layers.0.v_proj            0.03217       37.43%              0.031%
layers.0.o_proj            0.04526       44.53%              0.022%
layers.0.mlp.gate_proj     0.14557       45.83%              0.007%
```

**结论**：有 34~46% 的权重处于"离量化边界足够近"的带内，**翻转在物理上是完全可能的**（不是"锁死"）。但 lr=1e-5 在 20 步内的总位移只有量化步长的 **0.004%~0.031%**——**要跨越边界需要约 3000~25000 步**。而探针总共只跑 200 步。

**所以 flip=0 的真身是：探针的 200 步预算 + lr=1e-5，在物理上不可能观测到任何符号翻转。这不是模型行为，是测量窗口不足。**

外部回答主张的"α 与 lr 联合调度"因此**不是当前 loss 暴涨的主因**（lr 这么小，调度再精细也不会造成 7倍 loss 暴涨）。

## 那 loss 从 0.29 涨到 2.29 是什么？

**这个才是真信号，而且外部回答没解释对。**我的判断：

α 线性退火 1.0 → 0.0。在 `W_eff = W_q + α(W_latent − W_q).detach()` 里，**α 减小 = 前向越来越接近纯三值 W_q**。

- 训练开始时 α=1，W_eff=W_latent（精确等价原模型）⇒ loss 应该等于原模型水平
- α 下降时，前向被**强制拉向三值表示**，而**权重完全没动**（因为 lr 太小）⇒ 模型**没有任何机会补偿**这个扰动
- ⇒ **loss 暴涨是"在原地把一个能用的 fp32 表示，换成一个未经重新训练的纯三值表示"的必然代价**

这与 flip=0 是一致的、且互为因果：**权重不动（flip=0）+ α 退火推进（loss 涨）= 未补偿的三值化冲击**。

## 我实测给出的修正判据（比外部回答的更可执行）

外部回答建议测 sign alignment（vs 继承权重）。这条本身对，但我认为**还有一个更根本的量**：

**α-阶梯对照实验**：固定若干个 α 值（1.0 / 0.7 / 0.4 / 0.0），**每个都完整测一遍 holdout CE**，不做任何训练。
- 如果 α=1.0 的 CE 与原模型一致、α=0.0 的 CE 暴涨 ⇒ **确认是"三值化静态冲击"**，继承式失败的根因是"退火太快，来不及补偿"
- 这条实验**零训练成本**（4 次前向），且能一次性把"是模型不行还是训练不够"这个问题彻底切开

⇒ **这才是下一步该做的实验，而不是继续跑 200 步。**

## 由此得出的实施修正（写进探针）

外部回答推荐的中间路线我采纳前两条，第三条我加约束：

1. **只三值化 FFN，注意力保 fp16**（外部推荐，我同意：注意力承载检索/路由精度敏感，FFN 才是带宽大头）
2. **逐层退火**（先输出层，冻结后再往上）
3. **潜权重三值 QAT，影子权重 lr 单独设低 1~2 数量级** — ⚠️ 我加一条约束：**这条的前提是总训练预算足够让影子权重移动**。当前 200 步 @ lr=1e-5 的预算是**结构性的不足**（实测位移 0.004%~0.031%），任何"改变量"的方案在当前预算下都测不出区别。**必须先把训练预算提到能观测到翻转的量级（≥3000 步或 lr 提高1~2 个数量级），再比较方案。**

# 🔴 Q6：外部回答对，我错了

我说过"相对权重占比在 0.2B 最高（因为要加中文词表）"。**方向说反了。**

实测 135M checkpoint：

```
总计 162.8M
embedding   28.3M (17.4%)
非 embedding  134.5M (82.6%)
主干线性权重  106.2M (65.2%)
```

外部回答给的机制我核对了，是对的：`embedding = V·d` 随词表**线性**增长，`非embedding ≈ 12·L·d²` 随层数/宽度**二次**增长 ⇒ **规模越大，非 embedding 占比越高；小模型 embedding 占比反而最高。**

**这个纠正有实际后果，不是学术洁癖**：正因为 0.2B 这个 hidden=576 的小档 embedding 占比**偏高**，我们"embedding 保 fp16"的决策在这个规模**相对代价被推到了最高点**——直接把 b_eff 从 1.58 拉到 5.5，而其中最大的一块正是这个"保 fp16"的 embedding。

外部回答给的翻转点估计（非emb 占比 ≈ emb 占比 在 hidden≈700 / ~200M 附近交叉）与我实测的 17.4%/82.6% 一致方向——**0.2B 恰在翻转点附近**，所以"embedding 保 fp16"在这个规模**需要重新论证**，不能当成"照搬 BitNet 配方"就算完。

**⇒ 待办：0.2B 这一档需要单独核算 embedding 保 fp16 的真实代价与收益，不能默认沿用配方。**（不擅自改决策，但标记为必须重新论证的项。）

外部回答提的**部分量化 embedding**（低频三值、高频 fp16）方向正确，但它自己点出了坑（两套精度的梯度要分开，否则低频行梯度拉偏高频行）。挂起。

# ✅ Q2：采纳，且它直接改了 0.5B 的功能方向

外部回答确认了我对"联网=打破信息天花板"的怀疑，并给了关键的**第二枪**：

> 「信息天花板」只在「监督学习 + 固定先验」框架里成立。进入环境交互后，**先验本身在变，不是"信息量加法"，是"先验与信息互相耦合的动力学"**。

它给出的正确框架不是"三者之和"，而是**拆成两个天花板**：

| 天花板 | 上限是什么 | 联网能打破吗 |
|---|---|---|
| **静态知识天花板** | 语料可压缩信息量（先验固定时的静态上界） | ❌ 不能 |
| **动态能力天花板** | 环境交互的回报结构（POMDP 下的策略空间可达质量） | 🟡 能一部分——**因为联网给了"工具使用"这个新动作空间** |

**它还直接给出四项分离的结论**（对小模型）：增益大头是 **(b) 检索/外部记忆 + (d) 工具行动力**，不是 (a) 语料量。理由正好用我们自己的 N\* 算：3.5e9 token 只撑得起 193M 参数，**堆语料对小模型的边际收益极低**。

**⇒ 对我们的直接影响**：
1. "联网 = 自我学习开关"这个叙事**作为"打破信息天花板"是伪命题**（我们内部 L2 规则的表述需要修正，但**规则本身不需要推翻**——它本来就说的是语料上限）
2. **0.5B 联网功能的设计方向应该是"接工具"（action capability），不是"喂语料"（data feeding）**。这是实打实的架构决策修正。

**⇒ L2 规则修订建议**（不改变其约束力，只把定义分清）：
原：「能力上限 = 语料相对先验可压缩信息量」
新：**能力上限 = min(静态知识天花板, 动态能力天花板)**；两者分别受不同手段约束，联网只作用于后者。

#✅ Q10：外部回答把我们自己的矛盾解掉了

我们此前记过一个冲突："端侧常驻 vs 数据治理"（`P-10.3`），当时只识别出冲突存在，**没给解法**。外部回答给了两个可直接用的结构：

### 1. 「常驻但感知受限」= capability-based security

传感通道由**模型之外**的能力令牌门控，模型默认无麦克风能力，除非用户显式发放**带时效的令牌**。范式成熟（seL4 / WASM capability）。

**关键点：门控在策略层，不在模型自律。** 这正好符合我们的宪法③（进化即存在 ⇒ 不把安全寄托在模型自己守规矩上）。

### 2. 「不记住比记住更安全」的硬机制 + 分层解冲突

**硬保证**：遗忘必须有物理硬上限——每条记忆带 TTL，**存储层强制擦除，不经模型"决策"**。

它同时诚实指出这与"10MB 长期积累"**真实冲突且不可调和**，并给出解法——**分层**：

| 层 | 内容 | 机制 |
|---|---|---|
| **持久层** | 长期身份/偏好（对应我们的 10MB） | 量小、审慎、**带取代关系**（这正好接上我们已意识到的"记忆取代而非衰减"盲区） |
| **易失层** | 短期情境 | 量大、自动过期（TTL硬擦除） |

⇒ **我们之前把"取代 vs 衰减"当成一个孤立盲区，它其实要求分层存储才做得对。** 两个盲区是一个东西的两面。

### 3. 梯度上传在 0.5B 不安全（它反对的方案）

- gradient inversion 在小模型小 batch 下**可近似重建原文** ⇒ "只上传梯度/统计"**不够安全**
- DP-SGD 会显著吃掉小模型精度（小模型本来就靠 N\* 精打细算，DP 噪声直接抬高有效 N\*）
- **它给的最干净答案：本地训练 + 只联网读、不上传任何梯度/原文**，把"联网自学习"限定为「**读外部 + 本地消化**」

**⇒ 这和用户"联网=自我学习开关"的意图高度兼容，且不需要牺牲隐私。** 我认为这是本轮最有实操价值的一条。

# 🔴 盲区1：保函数 vs 三值化是路线级矛盾（本轮最高价值）

外部回答指出：我把这条矛盾**藏进了 Q5（γ 是全局标量）**，没有升格为路线级结论。

**它的元判断**：
> 「严格保函数」要求扩容对输出零扰动；「三值化」是 `round_clip(W/γ)·γ` 这个**非线性、依赖全矩阵统计量**的算子。
> **同一个模型无法同时严格成立二者——三值化本身就破坏保函数。**

**这个判断是对的，而且我们的文档确实在回避它。** 我们目前的做法是"分阶段"（扩容阶段保函数、0.5B 重新三值化），但**没有一条"何时可以放弃保函数"的判据**——这意味着 Q1 那个 200 步探针在纠结的东西，根子在这里。

**它建议的优先级律**（我采纳，写入宪法）：

| 阶段 | 最高律 | 理由 |
|---|---|---|
| **未饱和、还在学知识** | **保函数最高** | 旧知识零丢失，是扩容的前提 |
| **已饱和、要榨带宽** | **三值化收益 > 保函数损失**，显式放弃保函数、接受**可预算**跳变 | 此时模型已 plateau，保函数保护的是"已经不再增长的东西" |

**⇒ 这条律的真正价值：它给出了"可预算跳变"这个概念的合法性**，把我们此前含糊的"接受跳变"变成"跳变有预算、超预算回滚"。

**⇒ 同时它给出了 Q1 的正确解读框架**：
Q1 的 200 步探针在纠结"继承式三值化能不能保住认知"，但按这条律，0.4B→0.5B 是一个**主动放弃保函数**的决策点——所以正确的评估标准**不该是"跳变有多大"，而是"跳变是否在预算内 + 跳变后能否恢复"**。我原来的判据（Δℒ ≥ +1.2 判失败）隐含了"不该有大跳变"，这与优先级律冲突。

# ✅ Q11 + Q7 + Q8 + Q9：采纳要点

**Q11（行为连续性）**：外部回答给了比"行为差异摘要"更可测的量——固定探针输入量 **KL(旧输出分布 ‖ 新输出分布)** 或 logits 范数差（模型升级回归测试的成熟做法）。
- **量化跳变预算分配**（它的原话，我采纳）：**逐层量"三值化后该层输出对探针 logits 的变化"，跳变大 = 精度敏感层保 fp16，小 = 可安全三值化**。
  ⇒ 这条**正好可以和 Q1 外部推荐的"逐层 sign 一致性 <60% 的层保 fp16"合并成一个指标**，且以探针输出为准（比符号统计更贴近真实行为）。
- **判断者 = 用户 + 探针集，不是模型自己**——与 Q8 的 root of trust 同一原则，自洽。

**Q7（遗忘）**：它确认了我们的决策，且给了更强的理由：
- 纯权重遗忘可实现，但**可验证性只能"已知攻击下不可恢复"，不能"可证明不可恢复"**——现有 unlearning 绝大多数用白盒攻击评估，**换更强提取方法即失效，是根本性问题，不是工程没做好**
- **三值下更难验证**（不是更容易）：残余信息压缩进符号位联合分布，**位级可审计误导性强**（看起来好查，实际纠缠更深）
⇒ **外挂记忆库的核心优势不是"删除快"，是"删除可证明 + 不损失其他能力"。** 我们此前的选型理由（不可删契约）成立，且更硬了。

**Q8（验证者悖论）**：三条防御按强度排序，我采纳前两条为可立即做：
1. **预言机版本冻结 + 哈希校验**（改 hash 触发独立告警）— 成本近零
2. **"通过"必须附可独立复现的 trace**（proof-carrying 思路）— 成本低
3. 双预言机异源（下沉到预言机层）— 成本高，挂起
- 它确认"用户作为最终 root of trust"= Constitutional AI 的工程化，**是我们最扎实的一环，别削弱**
- 「验证者提升链」无成熟理论，最近的是 typed certifying compiler 传统 ⇒ 落地版：**把"预言机被修改"设为更高级RSI 动作，需独立于预言机的第二份证据（commit 签名 / 外部时间戳）**

**Q9（认主）**：双因子建议我采纳，但**主次与它相反**：
- 它建议：行为轨迹主因子 + 生物特征高价值操作二次确认
- **我采纳这个方向**（它比我原方案更实际——端侧常驻的连续交互轨迹是免费获得、累积性、难伪造的），但加一条约束：**生物特征仍是"删除权载体"的锚**，不能降级为纯二次确认——因为认主头同时承担删除权的绑定职责。
- **加密域比对（cancellable biometrics / secure sketch）挂起**：它会掉精度，而认主余弦间隙精度是硬需求。这个权衡我们没有数据，等有实测再说。

# 外部回答仍然没说清/说错的地方（我保留的质疑）

1. **Q1 归因错**：它说 lr/α 调度失配导致 loss 暴涨。我的实测显示 lr=1e-5 在 200 步内位移仅量化步长的 0.004%~0.031% ⇒ **调度不可能是主因**。真因是"α 退火推进 + 权重完全没动" = 未补偿的三值化冲击。它给的"提高影子权重 lr"方案在当前预算下**测不出区别**，必须先提预算。
2. **Q3 的有效秩判据未验证**：有效秩对量化扰动本身不稳定（量化正是降秩操作）。用它当准入判据，可能出现"量化后有效秩必然下降 ⇒ 所有模块都不达标"的自我否定。**需要先在已知好坏模块上标定它的判别力**，不能直接立为规则。
3. **Q5 说"每层单独统计 γ"，但没提一个它应该提的问题**：每层 γ 之后，**跨层加宽时新层的 γ 从哪来**？如果新层复制旧层，γ 应等于旧层（可精确保函数）；如果是零初始化，γ=0 需 clamp 到 1e-5 ⇒新层量化步长退化为 1e-5，**几乎全零**。这是一个真实的实现陷阱。
4. **盲区3 的存储成本没算**：血缘档案"每档不删"在 8B 档是数十 GB×N 代。我们记忆里已有B9（回滚经济学）但没把"血缘档案"和B9 合并核算。
5. **盲区2 我保留**（宪法级，不擅自降级），但它指出的自相矛盾**必须在 0.4B 之前决**，不能带到 0.5B 再发现。
