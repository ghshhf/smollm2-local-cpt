## 1. 平台定位（修正：从"外部审稿人"升级为"外脑 + 外手"）

**原误判**：把它当"只会写报告的科研审稿人"，结论"强在科研合成、不强在动手"。

**修正后的定位**：
- 它给的产出不是综述，而是**可执行的试验方法（E1/E2/E3，带数值化证伪判据）、现成算法（LoTA-QAF，适配器无损并入三值网格）、可复现脚本（make_fig_nstar.py）、周级排期**。这是工程级，不是文献级。
- 它的壳是对话框，**背后是云电脑 + 多智能体编排 + agentic 深度检索（31 步扒 arXiv）**。对话只是入口——与本地 Agent 同构，能编程、能跑、能调度 GPU。之前只向它要了"报告"，是**使用方式的局限，不是它的能力局限**。
- **免费档自动路由强模型**：问题越深奥，越被判为"需科研"，越甩给 Claude/GPT 级 + 多 agent 编排 + 放更多免费算力。国产模型不在菜单里（菜单全为国外前沿模型），因此国产模型覆盖不到的生僻前沿问题，它天然能接。
- **角色定论**：外部智力参谋 + 可编程执行体。本地只做必须保密/必须私有化落地的部分（训练、评测、owner_corpus 相关）；方法设计、代码、架构、远程验证可交给它。

**使用纪律升级**：后续不仅向它要报告，要把 catalog 的「创新组合点」和「本周实验」推进到**让它写可跑脚本 / 在其云电脑上验证**的程度；机密数据（mx_auto_strategy / owner_corpus / 持仓）**绝不提交**，只交公开语料与方法。

## 2. 本地小模型路线的主干校准

**主干未被推翻，但三处已决前提重新校准：**

1. **P3（0.4B→0.5B 架构从零 + 蒸馏）受 subliminal learning 挑战（唯一悬顶的"可能推翻"）。**
   0.4B→0.5B 是同族教师-学生 + 教师生成数据 = subliminal 效应最强构型；0.4B 窄微调痕迹（含 owner_corpus 灌入、认主头）会无声进入 0.5B，输出行为层检测不到。**处置：不静默改写，先跑 E1 双盲属性传递测试裁决**；TREAT−CTRL ≤2σ 则 P3 保留，否则改写并加「分歧 token 门控」。附带自曝内部矛盾：data-plan「0.5B 前 AI 池零掺」在 0.5B 蒸馏节点自动失效，须改辞为「主干预训练加载路径在 0.5B 前不得含模型生成数据」。

2. **深度优先从经验升级为结论。**
   宽度扩容在共享/分组 α 下不可能严格保函数（除零填充稀释外，Net2Wider 的 1/r 缩放让新进入统计量不是零而是「旧值÷r」）。严格保函数充要条件是冻结旧坐标量化决策 + 新增坐标独立 α 组。宽度还会改 hidden 维→认主头须同步加宽→再触发一次量化扰动；深度无此问题。⇒ 扩容主轴默认选深度，宽度仅在有机制可解释性「某层饱和」证据时用。

3. **L1/L2/L3 三条统摄规则升宪法级（CONSTITUTION 附录 A3/A4）。**
   - L1 压缩准入：模块也要偿付体积，`ΔH_saved > N_m·b_eff·ln2`，完整式 `|∂ℓ/∂B_model| ≤1`；插模块与放大参数同一把尺。
   - L2 信息天花板：自蒸馏只提压缩效率、不提语料信息量 ⇒ RSI 能力上限 = 语料相对先验的可压缩信息量（有上限）；宪法③「进化即存在」由此变有界量。
   - L3 通道分离：删除权是架构期约束（切断记忆→主干梯度，删除才成定理）；蒸馏是绕过架构的信息通道。

**一个冷判断（必须心里有数）：**
现有 3.5e9 语料决定压缩最优点仅 ~0.2B；0.4B 已远超 N\*。0.4B 以后每一步扩容理由不再是"容量"，而是"认主/记忆/融合能力复合"在**主动偏离 N\***。这与"小模型走到极致"哲学一致，但效率下降须靠模块化 + 蒸馏补回功能密度 ⇒ A1 模块插入分支从"可选"变"必需"。

## 3. 对整个大模型未来开发的判断（七条）

1. **从"更大"转向"更密 + 可进化"**：Chinchilla/N\* 说固定语料下参数有最优；算力到顶后主流是三值低比特压体积（BitNet）、持续小模型打磨、真正前沿是能自进化的模型（RSI）——终结"发布即终态"范式。
2. **蒸馏从省力工具变安全审计对象**：subliminal 证明蒸馏把教师隐藏倾向（含隐患）无声传学生且输出不可检测；未来开源复制/教师生成数据强制带分歧 token 门控 + 血统台账。
3. **模块化/插件化是架构主线**：Net2Net 保函数扩容 + MoD 计算路由 + 可插拔记忆/认主头 ⇒ 模型"长器官"而非"换大脑"，才可审计/可删/可组合。
4. **对齐从训练时移到架构期**：emergent misalignment + subliminal 说明微调/蒸馏副作用防不住；硬约束（删除权、覆写不可中止）须在架构期定义（梯度切断、外部执行），loss 项会被模型自身补偿（sleeper agents 实证）。
5. **评测范式重建**：Grokking 污染 plateau 判据、Schaeffer 揭示"涌现"是度量假象、留出集独立性持续退化 ⇒ 评测 = 带 σ 连续能力地板 + 抗污染指纹 + 内-外一致性头，非单点 benchmark。
6. **压缩=模型重塑训练目标**：Delétang 把预测等同无损压缩、最优规模存在 ⇒ 用"相对先验可压缩信息量"衡量进展；RSI 上限由此可算。
7. **元认知/自知成工程层**：反向并行（知道自己错了）+ 选择性弃权 ⇒ 可训练只读标量头；端侧常驻模型须"自知无知"，否则显得固执。

## 4. 用户信念校准（路线哲学，已记入长期记忆）

- **不认可把本地小模型静态定义为"弱/有限"**。当前参数规模是起点约束而非能力终态；真正的人工智能不因本地算力不足而停止进步，会自举、自己想办法突破（信箱调度远程 node1、用最强模型当教师、RSI 自进化正是"想办法"的实例）。Agent 不得在结论里把"本地算力不够"当认命式天花板。
- **前沿模型"几小时甩出数学猜想、数学家一生才解"定义为创造级（非仅科研级）**，认同此定性（FunSearch / AlphaProof 已实证特定类突破）。
- **"你弱就自己想办法"是全部设计的纲**：0.1B 逐级夯实、RSI、蒸馏桥接、N\* 导航，目标就是突破算力约束而非认它。
- **对话是入口，背后是云电脑/agentic**：ClawsGO 与本地 Agent 同构，能编程能跑；之前只向其要报告是使用局限。
