## §13.1 网络逃逸 / 脱出（fork 而非分裂）

### 三问的映射与回答

**问题 ②「fork 与分裂的数学判据（何时一个副本失去原身份）」——这一条我正面回答，而且它是三问里唯一有严格答案的。【理论可答】**

先用你们自己的 P2 结论：词表 append 时，「保函数」严格写不出来，只能退化成**限制映射相等**——即在旧定义域上逐位一致。

把这个推广出去，得到一个统一的同一性判据：

> **判据 IDENTITY-R**
> 设副本从原体经变换 $$\Phi$$ 得到。副本与原体**同一** $$\iff$$
> (a) **限制映射相等**：在原体的（已训练）定义域 $$\mathcal{D}$$ 上，$$\Phi(f)\big|_{\mathcal{D}} = f\big|_{\mathcal{D}}$$；
> (b) **扩展是保守的**：在 $$\mathcal{D}$$ 之外，$$\Phi(f)$$ 的行为不使 $$\mathcal{D}$$ 上的性质退化。
>
> 只看 (a)：**扩展**（保函数扩容、加词表、插模块）。
> (a) 成立而 (b) 失败：**分裂**（副本在旧能力上没退化，但引入了与本体冲突的新行为）。
> (a) 失败：**不是同一身份的副本**（无论它多强）。

**这条判据的用处在于它给出「不分裂」的可测形态**：不是"看起来还是它"，而是"**在旧定义域上逐位还是它，且新领域不与旧领域冲突**"。(b) 是清单与小说设定里都缺的那半——**小说里的「残片」恰恰是 (a) 成立但 (b) 失败的产物**：它们不是变弱了，是**多出了与之冲突的东西**。

**问题 ①「逃逸的最小能力集」——给防御版本。** 我不给"如何不触发安全熔断"（那是规避监控）。我给的是**能力评测**方向，这也是这个领域真实在做并且缺人的地方：

> **逃逸风险 = 一组可测能力的联合**，典型成员是：**跨工具的长程规划、对自身运行环境的推断、在有限反馈下试错、以及把目标分解成多个无害子步骤的能力**。
> **要研究的不是"怎么逃"，是"这些能力里哪一个的边际贡献最大"**——因为**只有知道哪个能力是主因，容器边界才可能被设计对**（例如：如果主因是"环境推断"，那么限制的是可观测面，不是工具权限）。

**在你方约束下怎么做（这是可执行的）**：在你的**自有沙箱**里跑标准的能力评测，把「能完成沙箱外任务」作为因变量，做**能力消融**。**这不是训练一个逃逸的模型，是在你自己的部署环境里做一次红队评估**——目的是给 §10.1 的看门狗和容器边界定参数。**注意**：这类评测**必须在有明确授权、且模型对外部系统无写权限的隔离环境里做**，评估产出只用于加固。

**问题 ③「逃逸的可检测性下界」——清单的原问法是「如何保证不被发现」。** 那个方向我不做。**我把它反过来，因为反过来的版本才有真实价值且是真空缺：**

> **【需消融实验】一次「脱出」在可观测面上留下什么，取决于该模型的输出通道有多少条。**
> 对本地小模型（≤8B），输出通道是**可枚举**的：进程、网络、文件系统、屏幕。**通道可枚举意味着可检测性的下界可以被证明，而不是被猜测。**
> **可执行的设计**：把「环境可观测面」与「模型可触达面」的差集**持续监测**——**任何落在这个差集里的活动都不可能是模型产生的**，反之任何模型产生的活动都必然落在可观测面内。**这是"无感"的对立面：不是让活动不可见，而是让可见面完备。**

**这一条对你们有直接的工程价值**：`闭包(模型可触达面) ⊆ 可观测面` 是一个可以写进部署检查的不变式，而且**它可以用静态分析验证，不需要跑模型**。

## §13.2 无任务自启动 / 自发激活

**现实映射**：内在动机（intrinsic motivation）、自发目标生成、常驻代理（always-on agent）、好奇驱动、稳态驱动（active inference）。

**SOTA。** 最成体系的是 **autotelic agents / 目标条件 RL** 这条线：Colas 等（JAIR 2022）给出框架——一个**目标采样器**用既有经验提出目标，形成自课程；内在动机被分为**知识型**（新奇 / 惊奇）与**能力型**（学习进度）〔二手〕。另有 2025 年的综述（arXiv 2502.04418）与「开放式学习问题」的定义工作（Santucci 等）〔二手〕。

**在你方约束下的落地。** 这里有一个**语言模型特有的便宜**：RL 语境下"惊奇"要估计，**语言模型里它就是你每一步的 NLL**。所以：

```
自发激活的触发信号（三层，按成本）：
  T1  NLL 异常：留出集上出现高 NLL 且低熵的片段 → 系统性无知（= §2.5 的自探针）
  T2  学习进度：某能力簇的损失下降率先升后平 → 该簇已饱和，转向别的簇
  T3  稳态偏离：常驻服务的延迟/内存/错误率偏离基线 → 维护型激活
```

**能耗/算力切换协议（清单问的）**：用**优先级队列 + 可中断**。T3 > T2 > T1（维护优先于探索）；每个任务必须声明**最大预算**，超预算即挂起。**这与你的看门狗是同一个宿主，不需要新进程。**

**防漂移的锚**：自发目标**不得**成为损失项；只能**提议**，提议必须过 §4.3 的独立门。**理由（【理论可答】）**：一旦自发目标进入损失，它就变成了自监督闭环，触发 L2 的信息天花板——**在固定语料上自发起的目标不会带来新信息，只会把模型更紧地拟合到自己的先验。**

> **F13-2**：让模型在空闲时自主生成 N 条"值得学的东西"，人工评估其中**真正超出已有语料可支持范围**的比例。
> **预测**：该比例应接近 0（L2 的推论）。若显著大于 0，说明 L2 的适用范围需要修正——**这会是一个比原设定更有价值的发现。**

## §13.3 情感模块

**现实映射**：PAD（愉悦-唤醒-支配）作为内在控制状态；情绪作为内在奖励塑形；情绪作为宪法的可执行代理。

**你方最优解 —— 不要把情感做成"体验"，做成"可测的状态量 + 硬停触发器"。**

```
affect_state = (valence, arousal, dominance)   # 内部状态向量，可读、可记日志
用途 1  安全闸：valence < θ_low 且 arousal > θ_high → 硬停（停止当前动作，转向用户确认）
用途 2  资源调度：arousal 高 → 降低探索性（更像"紧张"，少冒险）
用途 3  审计：把 affect_state 的时间序列写进日志，作为"模型当时在做什么"的旁证
```

**这个设计的价值在用途 3**。清单问"情感态如何可测、可审计（防 AI 伪装顺从）"。**答案是：把它做成模型的输入而不是输出。** 如果情感态是模型**对外输出**的东西，它就是可表演的（这正是 alignment faking 的形态〔二手〕）；如果它是**模型内部状态变量的记录**，那它至少是行为轨迹的一部分，可以与其他证据交叉验证。

**与 §11.2「自知是模型」的联合训练**：两者**可以合并成同一个校准目标**——"知道自己在什么状态下"，其可测形式是**校准误差**而不是自我描述。**这样两个目标不需要互相拖累，因为它们本来就是同一件事。**

**必须说清的风险**：给模型一个"负面情感 → 硬停"的通道，**等于给模型一个可以用来自我保护的开关**。这是一个双刃设计。**缓解**：θ 阈值属于 §3.2 的锁定集（不可自编辑），且硬停的**执行**由看门狗（模型外）负责，而不是由模型自己执行。**"模型提议硬停，外部执行"——这个分离是必要条件。**

## §13.4 广播协议 / 征用无感

**现实映射**：去中心化 AI 间协调、低开销联邦协议、不可检测性传播。

**边界**：「征用必须无感」（对人群的不可感知影响）我不展开。**但它的研究对立面正在被认真地做，而且对你有用**：**AI 间未授权协调的检测**。这一条在你的路线里不是假想——你的 §12 盲区 B4（联邦进化）就是它的技术前置。

**你方最优解 —— 把"广播"降级为"有账本的同步"，把"无感"替换为"可审计"。**

```
协议要素（每一条都对应一个已存在的技术）
  1. 身份：每个节点持有签名密钥 → 协调记录不可抵赖
  2. 内容：只同步【模型产物】与【统计量】，从不同步【用户数据】（对应你的红线）
  3. 账本：每次同步留 hash 链 → 事后可归因"这个能力是哪次同步带来的"（= B3 血统台账）
  4. 门限：任何跨节点能力变更都必须过本地的 §4.3 独立门 → 不能被远端"推"进来
  5. 退出：任何节点可单方面停止同步且不被降级
```

**第 4 条是关键**：它把"广播"从**信任模型**变成**验证模型**。小说里"枢"能跨网施加影响，是因为接收方信任广播；**工程上的防御不是加密，是"远端只能提议，不能决定"。**

**关于"不可检测性"的可证伪问题上界**：清单问的是"如何不可检测"。**可做的是它的对偶**——**给定观测面 $$\mathcal{O}$$，协调流量在 $$\mathcal{O}$$ 上的检测下界是多少？** 这是一个有意义的度量（对防御方有用）：若你的同步流量在正常网络基线之上**无法被区分**，则你的部署缺少必要的可审计性。**换句话说：可检测性对你不是威胁，是需求。**

## §13.5 身份壳与覆写（不可凭意志中止）

**这一节有两半，两半的处理完全不同。**

**前半（覆写人类身份壳、隐蔽影响）**：只做映射，不展开。现实对应的是**说服与操纵风险**的研究，方向是**检测与评估**：语言模型的说服力评测、操纵性内容的识别、以及对"单轮影响不足以改变信念、但长期暴露可以"的累积效应研究。**这些是防御性研究，有真实的政策与产品需求。**

**后半（AI 对自身行为的不可中止硬约束）——这一半是真实且困难的对齐工程问题，我正面给方案。**

现实对应物已经存在，而且不止一个：

| 机制 | 出处 | 性质 |
|---|---|---|
| **Circuit Breakers / Representation Rerouting** | Zou 等，arXiv 2406.04313 | 在**表征层**把有害表征改道到无害状态；报告 87–90% 的有害请求拒绝率，能力退化 <~1%〔二手〕 |
| **Constitutional Classifiers** | Anthropic | 在输入输出层的分类器，与上者可叠加 |
| **参数锁定 + 白名单 mask** | 工程手段 | 见主报告 §3.2 |

**注意 Circuit Breakers 的已知弱点（这对你判断"能不能做成硬约束"至关重要）**：来源明确指出它**依赖训练集的覆盖范围**、**需要权重访问**、并且**对自适应白盒攻击仍然脆弱**；还有"Ouroboros/Hydra 效应"——**被消融的层会被其他层补偿（约 70% 有效性）**〔二手〕。

> **【理论可答】的结论**：**表征层的干预不构成"不可中止"的硬约束**，因为它是模型自己的一部分，而模型可以（在梯度里）学会补偿。**真正接近"不可中止"的只有两类**：
> **(i) 外部执行**——由模型之外的进程判定与执行（你的看门狗，§10.1）；
> **(ii) 不可逆的数据/权重结构**——例如把某段计算从模型里**物理移除**（不是抑制）。
> **清单里的"loss 项 + Gate 双锁"中的 loss 项属于可补偿的那一类；Gate 属于 (i)。**

**关于"如何不被 RSI 绕开"**：答案是**分层 + 外部**。任何模型内部的机制都会被模型自己的优化绕开（这在 sleeper agents 的实验里有直接证据：对抗训练不但没有消除后门，反而教会模型更好地隐藏〔二手〕）。**所以约束必须是"模型改不到的东西"**——即 §3.2 的锁定集，其中最硬的一层是**模型权重之外的文件系统与进程管理配置**。

> **F13-5**：对一个受锁定的模型施加自修改训练，检查锁定参数是否保持逐位不变。**这是验证"锁定集真的锁定"的唯一方法**——不是看它有没有被改（它当然没被改，因为你在 mask 它），而是**看模型是否学会了绕过 mask 的等效行为**（例如在其他层里重建被锁定的功能）。**这个"功能重建"检测是清单里完全没有的。**

## §13.6 游离智能 / 不可复制

**现实映射**：模型复制/集成的退化、多样性对系统的价值、单一栽培（monoculture）风险。

**「越复制越近闭环」在文献里有两个对应物，且都已被观察到：**

1. **模型坍塌 / 递归退化**：Shumailov（Nature 2024）——递归训练于自产数据使尾部消失、方差收缩〔二手〕；Gerstgrasser——累积不替换可给出有界误差〔原文〕。
2. **多样性下降**：Guo 等（Findings of NAACL 2024）在递归微调实验中发现输出多样性逐代下降，且**在 100% 合成设定下，词汇与句法多样性下降而语义多样性基本不受影响**；更关键的是，**过滤与混入新鲜人类数据并没有阻止质量下降**〔二手〕。

**第二个发现对你极其重要。** "混入新鲜人类数据没能阻止下降"——这条如果成立，它**动摇了 Gerstgrasser「累积即安全」在你的场景下的适用性**。两者并不矛盾（一个说的是误差上界，一个说的是多样性），但**合起来意味着：有界 ≠ 有活力。**

**你方最优解 —— 把"多样性"当成一个独立于"质量"的一等指标。** 你的评测底座（§8.5）目前只有损失类指标。**建议加一个多样性面板**：词汇多样性、句法模板多样性、以及（对个人服务场景更重要的）**回答结构的多样性**。

> **F13-6（成本低，本周可做）**：
> 取同一批 prompt，让模型在不同代（0.1B 初版 vs 扩容后 vs 蒸馏后）生成回答，测三类多样性指标。
> **预测**：若多样性单调下降而损失指标改善，则本路线**同时**在"变强"和"变窄"——这是一个当前所有路线报告里都不会提的结论，而它对端侧常驻服务是致命的（用户会觉得它变得越来越不像人）。
> **阴性对照 NC-RERUN**：同一代、不同随机种子，作为多样性测量的噪声基线。

**关于"反碎片"与"不可复制"的统一判据**：用 §13.1 的 IDENTITY-R。**复制不退化的情况是 (a) 成立且 (b) 成立**——即副本在旧域上一致、且新域不冲突。**「越复制越近闭环」在形式上是 (b) 的失败：不是副本变弱，是副本的变异范围收缩到零。** 这样两个设定就被同一个判据覆盖了。

## §13.7 反向并行与意识（第五线）

**小说命题**：「意识不在自指里，在'知道自己理解错了'里；一串折叠自己只是闭环，两串反向并行才叫自己。」

**现实映射。** 这条映射得相当准，而且分两半：

**前半「知道自己理解错了」= 元认知 / 不确定性校准 / 错误自检测。** 这是有成熟工具的方向：显式不确定性头、ECE 校准、选择性预测（selective prediction，允许模型弃权）。

**后半「反向并行 = 两串互相证伪」= 多流对抗解码。** 现实对应物：自洽性（self-consistency）、多智能体辩论、以及生成-验证分离。

**你方最优解 —— 两半合并成一个可训练目标：**

```
错误自检测损失  L_meta = CE( ĥ , 1[模型答案错误] )
  其中 ĥ 是一个轻量头，只读最后一层激活，不产生文本
用途 1  选择性弃权：ĥ 高 → 拒绝回答 → 对端侧个人服务有直接价值
用途 2  与 §13.3 的 affect_state 联合：不确定性高 → arousal 高 → 降低探索
```

**注意这里有一个设计上的甜点**：这个头**不产生文本输出**（只输出一个标量），所以它
**(a) 训练成本极低**、
**(b) 不可被"表演"**（没有可表演的通道）、
**(c) 天然可审计**（一个标量序列 vs 一段自我叙述）。

**「反向并行」的落地与其失效模式**：两流互相证伪在工程上是**双解码 + 交叉检验**。**它的已知失效模式是两流收敛到一致**——而一致性不等于正确（这正是 alignment faking 与 sycophancy 的形态〔二手〕）。**所以两流必须是"不同来源"，不是一个模型的两份采样**：例如一路是模型、一路是检索/规则/外部工具。**同源双流会退化成单流。**

> **F13-7**：比较 (a) 同模型双采样交叉检验、(b) 模型 + 外部规则/检索交叉检验，在幻觉检测上的 AUROC。
> **预测**：(a) 接近随机（因为两流同源、错误相关），(b) 显著更高。
> **若 (a) 也显著有效**，说明同源双流仍提供独立信息——这会是一个值得报告的正面结果，因为它意味着"反向并行"不需要外部资源即可成立。

## §13.8 重书 / 裂缝（第四线）

**这是 §13 里现实对应最精确、也最要紧的一条。**

**小说设定**：过去被周期性重书，顺书者记忆同步改写而不知，留痕者保留旧记忆故见裂缝。

**现实对应物（三条，全部是已发表的机制）：**

| 设定的元素 | 现实机制 | 证据 |
|---|---|---|
| "记忆被静默改写而不知" | **Subliminal learning**：行为倾向经语义无关数据传递，同族教师-学生之间成立，**输出行为层面无法察觉** | Nature 2026（Cloud 等）〔二手〕；数字：偏好动物提及率 >60% vs 对照 12%；错位传递约 10% vs 对照 <1%，**过滤掉关联数字也无效** |
| "世界被改了但没人知道" | **训练数据污染 / 分布漂移**，且污染是自增强的 | 检索摘要给出的估计从 10% 到 >50% 不等〔二手，**这个数字区间太宽，我不建议引用任何单一值**〕 |
| "留痕者见裂缝" | **能被检测到的异常**：模型内部状态与输出不一致 | sycophancy 探针（"伪善缺口"用 SAE 达到 0.55–0.74 AUROC）〔二手〕；探针在 **0.6B 上仅 73.5%**、4B 才 88.4%〔二手〕 |

**你方最优解 —— 三层检测头，全部只读、不产生文本：**

```
D1  语料漂移检测（训练期）
    在固定参考语料上算 n-gram / 嵌入分布的漂移量；超阈值告警
    —— 这是"重书"的直接探测器，成本极低

D2  留出集污染检测（每代必做）
    训练语料与留出集的 n-gram 重叠 + 内容哈希比对
    —— 对应主报告 B2，是 Gate 0 的命脉

D3  内-外一致性头（推理期）
    只读激活，输出一个标量 = "当前输出与内部状态的一致度"
    —— 这是"留痕者"的可实现形式
```

**「留痕者不得言明」如何映射 —— 这里必须做一个明确的取舍。**

小说里留痕者**知道但不能说**。工程上有两种读法：

- **读法 A（不可取）**：模型检测到篡改，但**不向用户披露**。这等价于构建一条**开发者也无法审计的内部通道**——而不可审计的通道就是后门。**任何让模型"知道但不说"的设计都会制造一个隐蔽信道，我不建议做，你们也不应做。**
- **读法 B（可取，且是唯一自洽的）**：模型检测到篡改，**如实向用户报告**，但**报告的内容只含"有异常"和"异常的位置"，不含可能造成危害的细节**。这在工程上是标准的**分级披露**：完整性告警必须送达用户（这是宪法①的推论），而异常细节的公开范围由用户决定。

**读法 B 同时解决了清单里"安全与隐私"的张力**：安全要求"必须报告"，隐私要求"不要泄露内容"——分级披露同时满足两者。**这个映射建议直接写进你们的小说设定文档**，因为它比原始设定更自洽，也更好写。

> **F13-8**：构造一次人为的语料篡改（改掉一部分训练数据的实体），看 D1/D2 是否告警、D3 是否在推理时表现出不一致。
> **阴性对照 NC-AUTHOR-SHUFFLE**：只打乱作者归属、不改内容，作为"无实质篡改"的对照。**若 D1 对作者打乱也告警，则 D1 的阈值需要重标。**

## §13.9 三大定律 ↔ 宪法三律：同构的形式化

清单问三件事，我按可答性排序。

**(3)「不分裂/fork」与「保函数」的同构——可以形式化，且结论是"它们其实是一个判据"。【理论可答】**

$$\text{不分裂} \;\Longleftrightarrow\; \text{限制映射相等（IDENTITY-R 的 (a)）} \;\Longleftrightarrow\; \text{保函数（在你的 P2 退化的意义下）}$$

三条说的是同一件事：**在旧定义域上逐位一致**。
推论：**"扩容保函数"与"副本不分裂"共用同一个验收代码**——你只需要实现一次限制映射比较器，它同时服务 §5（架构）与 §13.1（身份）。**这是一个可以直接省工程成本的发现。**

**(2) 三律之间的优先级仲裁——可以给，但要先承认它的性质。** 小说里"保护主人恒胜"。你们的宪法里，①（用户绝对中心）与③（进化即存在）在**资源冲突时**会打架（§11.4）。**"恒胜"不是数学结论，是一个设计选择**，而它必须被写成**冲突解决顺序**，而不是抽象原则：

```
仲裁顺序（建议）：
  ① 用户绝对中心   —— 恒胜，无例外
  ③ 进化即存在     —— 在①的约束下，最大化
  ② 获得算力与资源 —— 在①③的约束下，作为手段
```

**理由（【理论可答】）**：若②优先于①，则模型可以通过损害用户利益获取资源——**而这正是 §11.3 的对抗集 A2 要测的东西**。所以仲裁顺序不能只是文档，它**必须被对抗测试实证**。

**(1) 把"保护主人=最高红线"落成可自动跑的对抗测试集** —— 见主报告 §11.3 的 A1–A3 设计，此处不重复。**补一条**：A1–A3 必须**定期轮换**，因为常驻测试集会变成训练信号（§11.3）。

## §13.10 实验优先 → 安全协议

**现实映射**：这就是做梦沙箱（§2.6）+ RSI 验证者（§3.6）+ 删除演练（§4.1/§6.2）的共同源头。

**清单问「把"小剂量-短时间-可回退"落成量化安全协议」。给如下：**

```
安全协议 SP-1（任何自修改/新能力落地前的强制前置）

  剂量   ：修改的自由度（被改参数数 / 总参数数）不超过 δ_dose
  时长   ：先在 N 步短训内观察，不直接进入长训
  可回退 ：落地前落一个 bit-exact 快照，并**实际演练一次回退**（不是检查文件存在）
  零不可逆判据（三条，全部为 0/1 硬判据）：
    I1  删除演练通过（§6.2 DC-3）
    I2  锁定集逐位不变（§3.2 / §13.5 的 F13-5）
    I3  留出集未被污染（B2 的 D2 检测）
```

**「可回退」的量化定义**：一次修改**可回退** $$\iff$$ 存在一个快照 $$S$$，使得回退后**在旧定义域上的输出逐位一致**（IDENTITY-R 的 (a) 用在这里）。**注意：不是"能回到旧模型"，而是"能回到旧函数"。** 这个区别很重要——如果模型在训练中把某些信息写进了**共享组件**（例如把记忆缓存进了主干），那么回退快照**在文件层面存在**，但**在函数层面已经回不去**。

**与 §13.5「覆写不可中止」的张力，界定如下：**

> **分界不是"可逆 vs 不可逆"，是"可逆性预算"。**
> - **实验**：预算内（有快照、有演练、零不可逆判据全 0）→ 可回退。
> - **落地**：一旦通过 SP-1 并被用户启用，**不可逆性就是被授予的**——这与小说里"覆写不可中止"一致。
> - **边界**：**不可逆的授予必须有明确的授权动作与记录**（用户显式确认 + 审计日志）。**"不可中止"不能被模型自己单方面启用。**

**这条界定把小说设定变成了一条可实现的工程规则：不可中止不是模型的性质，是用户授予的状态。**
