# 依赖配置台账

按 §4 逐项标注。**「影响量级」一栏说明缺它会导致哪一类结论无法判定，而不是笼统的"有影响"。**

| # | 配置项 | 状态 | 影响量级 | 具体卡住什么 |
|---|---|---|---|---|
| 1 | 语料总规模与重复 epoch 数 | **缺失** | **决定性** | Gate 1 的"数据受限"分支无法判定；最优容量点无法与"语料不够"区分；重复 epoch 收益衰减无法预估 → 3B/8B 是否值得上完全无法判断 |
| 2 | 量化尺度粒度（逐行 vs 共享 α） | **缺失** | **决定性** | Gate 4：共享 α 会让 append 稀释旧行、两个函数都保不住；也决定 1.70% 跳变能否外推 |
| 3 | embedding / lm_head 是否在三值量化范围内 | **缺失** | **决定性** | Gate 4 与完整比特账（BS-5）：决定词表 append 的稀释问题是否存在，以及 adjusted rate 能否计算 |
| 4 | 加词表时是否改动 tokenizer 匹配规则 | **缺失** | **决定性** | 决定 loss 的**定义域**是否改变；不改则旧文本 id 序列不变（影响面小），改则旧 token 的 target 与上下文同时变化（影响面大） |
| 5 | 蒸馏损失的具体构成 | **缺失** | 高 | Gate 6 的对照臂无法设计；前向 KL / 反向 KL / JSD 的差异在 5 万+ 词表下不可忽略 |
| 6 | 记忆层的数据政策（个人数据能否用于闭环训练） | **缺失** | **决定性 + 治理闸门** | Gate 6/7/8 全部受阻；且决定 BS-8 的删除权方案是否必须存在（若允许，删除权是硬需求；若不允许，选型空间收窄） |
| 7 | 各档位实际参数量与训练步数 | **部分** | 高 | 只有 0.1→8B 的跨度，缺层数/宽度/步数 → Gate 2 的算力对照无法核算，只能给方向不能给量级 |
| 8 | 已实测 1.70% 跳变对应的加宽比例与模型规模 | **缺失** | 中高 | 决定该数字能否外推到 3B/8B（Q14） |
| 9 | owner_corpus 的规模与来源数 | **缺失** | 中高 | Gate 5：负样本池大小直接决定认主头是否可行；来源数太少则负样本不足 |
| 10 | 目标端侧硬件的具体型号与内存预算 | **缺失** | 中 | Gate 7 的延迟/内存实测无法设定预算，BS-10 的"带宽 vs FLOPs"判断无法落定 |

## 使用规则

1. **凡定性为「缺失」且影响量级为「决定性」的项（#1–#4、#6），本审计中相关结论一律不作定量判断**，报告中已逐处标注。
2. 第 1、2、3、6 项属于"给了就能立刻大幅提升判断质量"的类型，建议优先补齐——它们不需要跑实验，只需要读你们自己的代码与配置。
3. 第 5、7、8、9 项可以在对应 Gate 的实验准备阶段顺带补齐。
