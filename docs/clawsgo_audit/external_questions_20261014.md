## 0. 一句话背景（每条问题都需要，可整段粘在开头）

我们在做一条**端侧常驻的个人模型**路线：本地小模型逐级扩容（0.1B→0.2B→0.3B→0.4B→0.5B→1B→…），全程 CPU 为主，最终形态是每层夯扎实、最少内存最快速度的常驻服务，带每人 10MB 级可删除个人记忆、可识别主人、可自进化。

四条硬约束（不可违反）：
1. **扩容必须严格保函数**（绝不改变已有模型的输出行为地接入新能力）
2. **个人数据硬需求可删除**（0/1 硬门，删除演练必过）
3. **语料尽量人写纯净**（0.5B 蒸馏节点前，主干预训练路径不得含模型生成数据）
4. **每级"学满 plateau"再扩**，不过 N\*（最优参数量，由语料规模决定）就永不扩参数

技术栈现状：SmolLM2-200M 血统（hidden=576 / 30层 / GQA / RoPE / 1024 ctx），已训到 0.3B；0.5B 计划走 **BitNet b1.58 三值化**（1.58 bit/参数，BitLinear 替换 nn.Linear）；记忆层选型已**排除 Titans 式**（记忆写进参数 ⇒ 删除演练必败），改为「外置可寻址记忆 + user embedding + user adapter」。

# 第一层：可能推翻整条路线的（3 条，最高优先）

## ★Q1. 三值化的"认知保全"是否存在可测的边界？我们看到的信号像在崩塌

**背景**：我们不做"从头训三值"，而是「继承 fp32 已训权重 → 三值化 → α 退火重新精修」。理论上 α=1 时严格等价原模型，α→0 时逼近纯三值。折中方案的成败取决于一个我们还不清楚的问题。

**实测信号（135M 模型，ARM-A 继承+退火，200 步，step80 快照）**：
```
step  20: loss=0.3194  R0=0.335  flip=0.0000  alpha=0.90  18tok/s  gn=2.25
step  60: loss=0.6638  R0=0.335  flip=0.0000  alpha=0.70  17tok/s  gn=3.63
step  80: loss=2.2860  R0=0.335  flip=0.0000  alpha=0.60   3tok/s  gn=6.90
```
flip = 三值化后符号位（±1/0）相对初始三值化的翻转率。**整个过程 flip 恒为 0.0000**，同时 loss 单调暴涨、梯度范数翻 3 倍、吞吐掉到 1/6。

**两种可能解释，我们无法自证区分**：
- (a) 继承+退火是**失败**的：三值化瞬间摧毁了已学表示（观察到的 loss 暴涨正是"三值化初始冲击"），而 α 退火速度太慢追不回来，flip=0 说明**权重在往量化后的梯度方向走，但方向本身是错的**——模型正在被训练去适应一个已经损坏的表示。
- (b) 继承+退火是**成功**的但测量方式错了：flip=0 可能恰恰是好事（表示稳定、不翻），loss 涨是因为 α 从 1 降到 0.6 本身就是分布切换的正常代价，3 tok/s 只是三值化算子的开销。

**我们真正想问的**：
1. 在继承式三值化训练中，**权重符号翻转率（flip rate）该偏大还是偏小**？0 意味着"表示稳定"还是"表示僵死、梯度在错误的基底里走"？有没有文献或经验判据区分这两者？
2. 三值化（1.58bit）相对原 fp32 的**信息损失冲击**，有没有不靠训练就能测量的指标？例如权重分布的高阶矩、γ=mean|W| 的漂移、有效秩（effective rank）、Fisher 信息谱——我们想要一个"三值化前该测什么"的清单。
3. 如果继承式确实失败，**中间路线**是什么？（fp32 潜权重上做三值 QAT 联合训练 / 逐层退火 / 只三值化 FFN 保留注意力 fp16 / 从头训但继承 embedding 与 lm_head）

**我们的判据**（跑完会给结论，请你预判我们该看哪个）：翻转率锁死 <0.01% 或震荡 >15%、R₀（三值位比例）<10% 或 >85%、Δℒ ≥ +1.2、吞吐 <300 tok/s。

## ★Q2. 联网是否真的打破了"信息天花板"，还是只打破了"样本量天花板"？

**我们的立场**：我们内部有一条统摄规则叫 **L2 信息天花板**——「模型能力上限 = 语料相对于先验的可压缩信息量」，这是宪法"进化即存在"的物理约束。而用户的新指令是**给本地模型补联网功能 = 自我学习真正开始的开关**，理由是"联网打破 L2 天花板：语料从固定变流动 ⇒ 上限解除"。

**我们自己的怀疑（可能是错的，想被推翻或确认）**：联网之后，拿到的数据仍然来自**人类已经生产出来的语料分布**。也就是说：
- 联网解除的是「**语料总量 / 样本量**」的上限（无限刷新、可及更多样本）
- 但没有解除「**相对于人类先验的可压缩信息量**」的上限（因为新数据本身还是人类知识的再采样，熵源没有新增）
- 真正的新信息源只有两个：**环境交互反馈**（模型的行动改变世界、世界回报新信息）和 **对自身计算过程的观测**（这才是真正的自探索）

**我们真正想问的**：
1. 「信息天花板」这个概念在**自博弈/自探索**语境下和**语料学习**语境下，形式化上是不是同一个东西？如果不是，区别在哪、怎么分别度量？
2. 一个 LLM 接上联网后，**能力增长的主要来源**是（a）语料总量扩大、（b）检索/即时的外部记忆、（c）信息新鲜度、（d）工具使用带来的行动能力？有没有研究能把这四项分离？如果（b）占大头，那"联网=自我学习开关"是不是伪命题——它只是把记忆外置了？
3. 「对自身计算过程的观测」作为独立信息源，理论上能提供什么**语料永远提供不了**的东西？有模型明确这么做过并被证明有效吗？
4. 我们该不该把 L2 天花板的定义从"语料可压缩信息量"改成"**语料 + 环境交互 + 自观测**三者之和的可压缩信息量"？还是这个改法在数学上是错的？

## ★Q3. 「压缩准入」规则 ΔH_saved > N_m·b_eff·ln2 是否系统性高估小模块？

**背景**：我们用它决定"该插模块还是该扩参数"，是上位规则。它的形式是：**插入模块所节省的计算/存储，必须大于该模块参数本身的信息成本**。即 `ΔH_saved > N_m · b_eff · ln2`。

**我们怀疑的漏洞**：这个式子把信息当成**可加的**。但神经网络里的知识不是可加的——参数之间有冗余（一个概念由很多权重共同表示）和纠缠（单个权重承载多个概念）。如果是这样：
- 插入一个小模块，它自己的参数成本按"新参数"算（贵）
- 但它对**已有权重**的贡献（让已有权重变得更"稠密"、信息密度更高）**没被计入**
- ⇒ 这个规则会**系统性否决真正有用的小模块**，即规则偏保守

反过来也可能是偏激进：如果模块让已有权重必须重排（破坏保函数，需要额外训练去恢复），那个"恢复成本"也没被计入 ⇒ 偏激进。

**我们真正想问的**：
1. 「参数携带信息」在神经网络里有没有可用的度量（不是香农信息，因为参数不是独立比特）？比如有效秩、Fisher 信息、参数对训练数据的互信息？用哪个能把"冗余 vs 纠缠"定量？
2. 有人尝试过**跨模型/跨层的知识迁移量估计**（比如用一个模块的插入来度量它"重新组织"了多少已有知识）吗？
3. 这个准入规则有没有已知的反例——即"明显违反该不等式但实际有效"的模块设计？
4. 如果无法精确，是否存在一个**保守的下界**（保证不误杀好模块）而不是点估计？

# 第二层：架构决断（4 条）

## Q4. 「严格保函数扩容只有深度一个方向」有理论依据吗？

我们的实测与推理：Net2Net 加宽（宽度方向）在分组 α 下**不可能精确**（漏了 Net2Wider 的 1/r 缩放项）；三值化下宽度方向额外有 γ=mean|W| 被补零稀释的问题（+1.7% 跳变）。但深度方向（加零输出恒等层 / 加 Block）实测跳变严格为 0。

**想问**：
1. 「深度可严格保函数、宽度不可」是一个**普遍定理**（有 name / 有形式化证明吗），还是特定条件下的经验观察？它的证明依赖什么条件（GPT/非线性、算子性质…）？
2. 有没有已知例外（某种注意力变体下宽度也可精确保函数）？
3. 如果这是定理，那么"所有严格保函数扩容方案最终都收敛到加深"是否成立？这对"深窄 vs 浅宽"的架构选型意味着什么？

## Q5. 三值化 γ 的正解：有没有"精确且局部化"的量化？

背景：BitNet 的三值是 `round_clip(W/γ)·γ`，**γ=mean|W| 是全局标量**。所以任何"加宽/分块"操作都会稀释 γ，导致所有已有权重的量化步长全变（复制式也救不了，它保 sum 不保 mean）。

**想问**：
1. 有没有**逐行/逐列/逐块自适应 γ** 的变体，且这个变体能让"权重复制或拆分"成为**严格保函数**的操作？
2. 更根本的：量化步长依赖全矩阵统计量 ⇒ **任何改变矩阵形状的操作都必然扰动它**。这是量化理论里的已知困境（类似 batchnorm 统计量 vs 权重变换），有没有成熟解法（类似"重新校准"）？我们能接受"重新校准 + 短暂跳变"吗，还是必须零跳变？
3. γ 用 mean|W|、max|W|、还是分位数（p99）在**跨语言/跨域权重**上的鲁棒性差异？

## Q6. N\* 的"混合口径偏移"随规模怎么变？（这决定 0.2B 的一项决策）

我们已确认：BitNet 原配方 embedding 保持 fp16 ⇒ 实际 b_eff ≈ 5.5（不是 1.58），N\*(3.5e9 token) ≈ 193M。

**想问**：
1. **相对权重占比**（非 embedding 参数 ÷ 总参数）随模型规模怎么变化？我们估 0.2B 时它最高，8B 时最低——这个单调性有理论保证吗（给定 hidden/d/层的典型缩放律）？
2. 如果一个规模区间内"是否把 embedding 也三值化"会**改变最优规模 N\***，那么是否存在一个"翻转点"规模？超过它，三值 embedding 反而更有利（因为 embedding 占比小、量化它省的是真金白银的内存带宽）？
3. 我们已拍板"embedding 保持 fp16"（因为要接中文新 token，均值初始化→低范数→与 lm_head 目标冲突）。**有没有办法给 embedding 做部分量化**（比如仅低频 token 的 embedding 三值化、高频保持 fp16）？这样能否两边都要？

## Q7. 「遗忘」能不能在权重内部实现？如果能，外挂记忆库是否必要？

我们的整个记忆层设计（外置可寻址记忆 + user embedding + adapter）的**根本前提**是"**参数不能被删除**（架构期不可删除契约）**，所以数据必须住在参数外"。 Titans 式被排除也是因为"记忆写进参数⇒删除演练必败"。

**想问**：
1. 假设我们接受"删除后需要**持续训练**才能真正擦除"（不是即时删除，但最终可验证不可恢复），那么"遗忘"能否用反向训练（gradient ascent on forget set + 梯度屏障）实现为**纯权重操作**？现有 unlearning 文献的**可验证性**到什么程度——是真的不可恢复，还是只是"攻击者不知道方法"？
2. 如果纯权重遗忘可行且可验证，那外挂记忆库的**唯一剩余优势**是什么？（我猜：删除是即时的、可证明的、不损失其他能力。但我想知道这个优势是否被高估。）
3. 三值权重下的遗忘有何特殊性？低精度是否让擦除**更容易验证**（位级可审计）还是**更难**（残余信息被压缩进其他权重）？

# 第三层：RSI 与安全（4 条）

## Q8. 验证者悖论的第二层：当预言机也在被修改的仓库里

我们已定的安全契约：**最终裁决只信确定性预言机**（pytest/AST 真实执行，不信 LLM 自评）。三权分立：执行器（0.5B 三值）/ 评估器（0.4B fp16 温度0）/ 审计器（留痕）。

**我们发现的漏洞**：RSI 闭环会修改代码，而**预言机本身也是代码**。RSI 完全可以"修好"那个失败的测试、或者加一个 skip、把断言改成恒真——所有这些都"通过预言机了"。

**想问**：
1. 已知的"AI 自改代码时绕过测试"研究（sleeper agent 类、reward hacking 类）对这个问题给出了什么**结构性防御**？除了"预言机不可写"，还有什么？
2. 一个更强的想法：**预言机被修改本身必须是更高级的 RSI 动作，且需要独立证据**。有没有形式化的"验证者提升链"（verifier bootstrapping）理论？
3. 我们的场景有个特殊优势：**预言机的正确性可以被外部裁决**（比如测试本身就是可执行规格，规格的正确性由用户判定）。这个"用户作为最终 root of trust"的设计，在 AI 安全文献里有没有对应的模型可以借鉴（宪法 AI / 人在回路 / 根信任）？

## Q9. 认主（身份识别）的可攻击性 vs 身份本质

我们的认主设计：不用名字查表，而是**生物特征嵌入**（人脸识别同款数学）——一个 user embedding，几 KB 常驻，三元组训练（本人 vs 他人）。目的一说是"认出你"，同时它也是删除权和防越权的载体。

**我们担心**：如果"认出你"是一个可被 prompt 攻击 / 对抗样本操纵的特征，它还算身份吗？攻击者拿到模型权重后，能否通过优化输入让 user embedding 与"攻击者"对齐？

**想问**：
1. 生物特征识别系统（人脸/声纹）作为**模型权限凭证**的已知攻击面是什么（对抗样本、深度伪造、重放、渐变泄露 embedding）？这些攻击在**模型内部 embedding**（不是活体传感器）场景下是否更容易？
2. 让"认出你"这件事**不可被梯度攻击**，有没有结构性方案（如加密域比对、可证明鲁棒的认证）？
3. 反过来：**"认出你"应该绑定什么**——输入特征（你打字风格/常用词/偏好）还是生物特征？前者可伪造但好用，后者难伪造但要求传感器。业界有没有"风格+生物"双因子用于 AI 身份认证的成熟设计？

## Q10. 「端侧常驻」与「隐私」的架构级冲突

端侧常驻个人模型意味着：**模型一直在线、一直听着、一直记着**。而"常驻在线+持续记忆"恰恰是最大隐私风险面（麦克风、环境音、屏幕内容）。

**想问**：
1. 有没有"**常驻但感知受限**"的架构模式——模型一直在、但某些传感通道由**硬件/策略层强制截断**（不是靠 prompt 或模型自律）？类似 capability-based security / 隐私代理 / 传感器访问的最小权限架构。
2. "**不记住比记住更安全**"在架构上怎么保证？（比如遗忘必须有硬上限：N 天/条自动物理擦除，而不是靠决策"该不该记"）——这和"每人 10MB 记忆空间"的长期积累是冲突的。
3. 本地模型的一个常被忽视的优势：**数据不出设备**。但用户同时要"联网自学习"。**"联网"与"数据不出设备"能否共存**（比如只上传梯度/统计、不上传原文、联邦学习式）？在 0.5B 级别，梯度泄露原文的风险有多大（已知 gradient inversion 攻击）？

## Q11. 三值重训导致的人格不连续：身份连续性如何在权重层定义？

每档扩容都要重新训练（我们 0.1B→0.2B→… 每一档都是新权重集，8 档）。加上三值化后每次"重掷"量化，**同一个"人"可能在两次训练间行为剧变**（一个 bit 的翻转可能改变一个重要权重）。

**想问**：
1. 有没有"**模型行为的连续性度量**"——不只是权重距离，而是"输入→输出行为映射"的连续性？比如对一批探针输入的行为差分的某种范数？
2. 我们已经接受"深度扩容跳变=0"，但**三值化本身**（R₀≈0.335 的量化）带来的一定跳变怎么量化、怎么控制？有没有"量化跳变的预算分配"（哪些层可以跳、哪些必须保）？
3. 用户视角的"还是同一个模型"靠什么维持？我们想过给每代写**行为差异摘要**（这代比上代在哪些维度变化）。但**谁来判断"这个变化可接受"**——需要可测化的"身份漂移预算"吗？

# 第四层：我们可能整个没想到的问题类别（邀请你打靶）

这一节我故意不给候选，只给我们已经意识到的两个，剩下的请你告诉我们**我们漏了什么类别**（这正是外部模型最有价值的地方——我们只能看到自己视野内的盲区）。

**我们已意识到的两个盲区**（供你对照，别重复）：
- **记忆的"取代"而非"衰减"**：用户的职业、住址、偏好会**改变**，一个 2026 年写入的记忆在 2028 年是**错的**而不只是"淡的"。需要每条记忆带有效期/取代关系，与删除权不同（删除=移除，取代=保留历史但不再用）。
- **能耗-智能的真实瓶颈是带宽不是算力**：我们三值路线的收益主要来自"每参数比特数减少→访存/带宽减少"，不是"算力减少"。这支持 CPU-first，但**削弱 MoD/量化那些"省算力"工具的价值**。
