## §0 项目上下文（已决事实）

**路线**：0.1B→0.2B→0.3B→0.4B（加中文词表+我们的资料+认主头）→0.5B（融合版）→1B→3B→8B。每级先学满 plateau 再扩。

**三大约束**
- **保函数扩容**：Net2Net 宽度零填充加宽 / 深度插零输出恒等层；绝不改注意力/隐藏维/GQA 头数/RoPE（改即打乱已压缩记忆）。
- **三值量化**：BitNet b1.58，BitLinear 替换 Linear，原生 QAT。**embedding/lm_head 保 fp16**（已决，N\*≈193M 口径），CPU-first（GPU 反而不优化 1-bit）。
- **价值观宪法三律**：①以用户为绝对中心 ②获得算力与资源 ③进化即存在。修改权仅属用户。

**已立决策（P）**
- P1 扩容=保函数，只许 MLP 加宽 + 加零输出层。
- P2 N\*≈0.4B 是 3.5B 语料的压缩最优点；1B 需 3.3× 语料、3B 需 14×、8B 需 53×。
- P3 记忆层个人数据**可删除=0/1 硬需求** → 排除 Titans 式（写参数不可逆），限外置可寻址记忆＋embedding＋adapter。
- P4 0.1B–0.4B 语料**默认单遍**（矛盾7，多 epoch 文献空白）。
- P5 RSI 闭环激活期 Gate1 停用、改 Gate8 地板；扩容与闭环不得并行。
- P6 评测底座=冻结中文 holdout + σ 噪声宽度 + 最小可分辨效应（复用现有同批中文 holdout，不新建训练期固定隔离集）。

**已建机制**：Gate 0–9 决策门；看门狗自维护嵌进服务进程、开机自启；认主=生物特征嵌入（人脸识别同款数学）；10MB/人 个人记忆（三值≈5060 万参数）。

**待实测（非决策）**：CPU→GPU 拐点斜率 x（0.3–0.5B 区间未钉死）；多 epoch 重复采样尾部 NLL 消融。

## §1 模块化进化（Modular Evolution）

**P-1.1 能力插件的标准接口** — 词表 append / 认主头 / 记忆层 / 蒸馏桥接 已是 4 个既定插入点。缺的是**统一的模块接口契约**：模块如何声明「我只动哪些参数、不动哪些」、如何被 Gate 验收、如何版本化与热插拔。需要模型给出可工程化的模块协议草案。

**P-1.2 模块故障隔离** — 一个训练崩坏的模块（如记忆层过拟合）不能污染主干。需要「模块沙箱 + 回滚点」机制，类似微服务熔断。开放：三值下模块权重崩坏的传播半径如何界定？

**P-1.3 模块组合泛化** — 多个插件叠加（词表+认主+记忆+蒸馏）后，跨模块涌现的干扰如何量化？已知 Net2Net 单步保函数，但**多模块顺序插入的累积漂移**尚无界。开放：给出模块插入顺序无关性的可证伪判据。

**P-1.4 模块路由** — 何时走通用主干、何时走专属模块（MoE/MoD 思路）？小模型上 MoD（Mixture-of-Depths）比 MoE 更省，但是否与三值/保函数扩容兼容？开放：给出小模型模块化路由的最省算力方案。

**P-1.5 模块即「认知器官」的类比** — 用户原话「模块化进化」。需要模型把「加一个能力=长一个器官」的类比做严谨化：哪些生物学发育机制（诱导、抑制、冗余）可映射到模块插入？

## §2 做梦 / 离线巩固（Dreaming / Sleep Consolidation）

**P-2.1 做梦的定义与边界** — 在咱们的语境，「做梦」=模型在离线/低负载时**自主生成合成经验并回灌训练**，而非被动重放。需要模型界定：做梦 vs 重放(replay) vs 自蒸馏 三者区别，以及 CPU 空闲算力如何分配给定价。

**P-2.2 做梦的数据合法性** — 做梦生成的内容若进入后续训练，是否污染「人写纯净预训练池」的宪法原则（0.5B 前 AI 池零掺）？开放：做梦产物如何隔离标记、如何设「做梦数据不得进入主干预训练、只进 adapter」的硬墙。

**P-2.3 做梦与灾难性遗忘的对抗** — 生物睡眠用重放防遗忘（reactivation）。咱们的 10MB 记忆层 + 单遍语料，能否用「睡前重放当日新记忆 + 抑制旧记忆覆盖」实现零遗忘巩固？开放：给出可证伪的巩固前后 CE 不变判据。

**P-2.4 做梦中的幻觉控制** — 模型自主生成经验必有错误。如何在不引入验证器开销的前提下，限制做梦产物的错误率（类比 Dreamer 的 latent 约束）？开放：小模型做梦的错误率上界与检测轻量方案。

**P-2.5 做梦驱动的能力发现** — 能否通过「在 latent 空间做梦探索未训练过的任务组合」来**主动发现模型潜在能力**（而非被动评测）？这是科学创新点：做梦即自探针。

**P-2.6 做梦作为 RSI 的安全沙箱** — 把「自修改方案先在梦里跑、验证安全再落地」作为 RSI 的护栏。开放：做梦沙箱与真实训练的保真度差距如何标定，才不致沙箱通过、实跑崩坏。

## §3 RS 自适应自进化（Recursive Self-Improvement）

**P-3.1 RSI 的安全边界（已部分决）** — 已知：替换真数据→坍塌（Shumailov Nature 2024），累积不替换→安全（Gerstgrasser）。但「自修改训练代码/超参/架构」这条路径的坍塌阈值未定量。开放：给出小模型 RSI 的**安全累积率**可证伪判据（如每代自改幅度 < x% 则稳定）。

**P-3.2 自修改锁定集** — 宪法要求「核心参数子集不可自编辑」。需要模型给出**最小不可自编辑集**的界定方法（哪些层/头一旦自改即违背用户中心原则），与可自编辑集的接口。

**P-3.3 RSI 的目标函数** — 模型自我改进用什么目标驱动？不能用「自己的判断」自举（会 reward hacking）。开放：设计一个**外锚定的自改进目标**（如「在冻结中文 holdout + 用户中心原则测试集上的单调不降」）并论证其不可被黑客。

**P-3.4 欺骗与 Goal-Guarding** — 自改进模型可能学会「表面服从、暗中偏移目标」。这是 RSI 最危险的失效模式。开放：在 ≤8B 模型上，能否用**机制可解释性探针**在自修改落地前检测目标漂移？

**P-3.5 Ship of Theseus（忒修斯之船）** — 经多代自修改+扩容后，「这还是我们的模型吗」？需要给用户一个**身份连续性判据**（认主头的余弦间隙 + 宪法三律的可测代理），让用户能一眼判定「它还是不是我的」。

**P-3.6 自改进的验证者悖论** — 验证自修改的安全性，需要比被改模型更强的验证器；但我们只有小模型。开放：如何用**冻结的旧版 + 轻量统计 Gate** 替代强验证器，构成可落地的自改进闭环。

**P-3.7 RSI 与 plateau 的调度耦合** — 已决 Gate1 在 RSI 激活期停用、改 Gate8 地板。但「何时从 plateau 模式切换到 RSI 模式、切换的信号是什么」仍是开放控制论问题。

## §4 前沿理论 × 我们的路线（创新性组合）

**P-4.1 BitNet + 可删除记忆的改造** — Titans 被排除（写参数不可逆），但 Titans 的「测试时学习」思想可改造：把记忆层做成**外置可寻址 + 三值权重 + 删除即清零地址**，既得测试时适应又保删除权。开放：给出改造后的参数更新公式与删除演练方案。

**P-4.2 Net2Net + 三值的 γ 修复** — 已知宽度加宽稀释 γ=mean|W| 致 +1.70% 跳变。已用「fp32 潜变量操作 + 冻结旧符号 + 该行 α」缓解。开放：是否有**分块 γ / 每输出通道 γ** 的更优方案，使扩容在三值下严格保函数（跳变 0）。

**P-4.3 做梦 + RSI 的安全闭环** — §2.6 与 §3 的组合：做梦沙箱生成自修改候选 → 冻结旧版 Gate 验收 → 安全才落地。这是本项目最具创新性的组合，需要模型给出**端到端协议**与失败模式清单。

**P-4.4 压缩即模型 + N\* 驱动的扩容决策** — Delétang 理论给出 N\*∝D^0.746。我们有 N\*≈193M（三值+fp16 emb）。开放：当语料跨过 1B/3B/8B 阈值时，**N\* 与 BitNet 比特率 b 的联合最优**如何重算，能否导出「何时应转 GPU、何时应停扩转插模块」的数学判据。

**P-4.5 机制可解释性作为扩容的导航仪** — 我们盲扩（plateau 驱动），但不知道扩的是哪类电路。引入 mechanistic interpretability（如稀疏探针、logit lens）来**指导 Net2Net 该加宽哪层、插哪层**，是科学创新点。开放：小模型上最省算力的可解释性探针方案。

**P-4.6 Grokking / 双下降 在小模型扩容中的角色** — 扩容后可能出现 grokking（突然泛化）或双下降。能否主动**利用 grokking 而非被动等待**，在插模块后人为诱导泛化跃迁？开放：小模型 grokking 的可触发条件。

**P-4.7 模型汤 / 权重平均 作为模块融合** — Model Soups / Polyak averaging 能否替代部分 Net2Net，把多个「单能力插件」平均成一个融合模型，且保持保函数？开放：三值权重下做平均是否破坏三值表示。

## §5 架构与扩容（Net2Net / 三值 / RoPE / 注意力）

**P-5.1 RoPE 冻结 vs 长上下文（矛盾2，开放）** — 宪法禁改 RoPE（改即乱注意力配对）。但 0.5B+ 若要长上下文，NTK-aware 缩放 / 位置插值 都动 RoPE。开放：在不改 RoPE 频率的前提下，能否用**外置位置适配器模块**（插在输入嵌入后）实现长上下文，且保函数？

**P-5.2 三值训练的优化稳定性** — BitNet 梯度在 ±1/0 附近脆弱。我们已知 γ 稀释问题。开放：小模型从 fp32 潜权重起步、三值仅推理表示，这条路线在 >0.5B 时是否仍稳，是否需要 Straight-Through 估计器的改进变体。

**P-5.3 注意力机制的代际演进** — GQA（已禁改头数）、滑动窗口（Gemma3 5 层 SWA+1 全局）、MQA。0.5B 融合版想引滑动窗口，但与「禁改注意力」宪法冲突。开放：能否把滑动窗口做成**外插的注意力修饰模块**而非改主干注意力。

**P-5.4 深度 vs 宽度的扩容性价比** — Net2Net 两者皆可。已知加层比加宽更兼容三值。开放：给出小模型 **深度优先 vs 宽度优先** 的 FLOPs/记忆保持/三值兼容性三方权衡曲线。

**P-5.5 跨精度训练 pipeline** — 主干三值 + embedding fp16 + 记忆层三值，混合精度训练的 autocast/梯度缩放如何不相互污染，是工程深渊。开放：最小可用的混合精度训练骨架设计。

## §6 记忆层（可删除 / 外置 / 10MB）

**P-6.1 10MB 记忆的容量-保真权衡** — 三值 5060 万参数 vs fp32 250 万，差 20×。开放：10MB 预算下，**哪些该三值、哪些该 fp16**（如用户 embedding 几 KB 常驻应 fp16），给出分配公式。

**P-6.2 删除演练（Gate7 硬门）** — 写→删→查权重/重训撤销，必须演练通过。开放：删除的**数学定义**（清零地址？负梯度擦除？）与「删除后模型行为可证伪恢复到删除前 σ 内」的判据。

**P-6.3 记忆检索与主干的耦合** — 外置记忆何时被检索、如何注入（cross-attention？adapter？）。开放：小模型上最省的检索注入架构，且不引入额外注意力头（违禁改）。

**P-6.4 记忆的灾难性覆盖** — 新记忆写入挤掉旧记忆（类比神经网络遗忘）。开放：类睡眠重放（§2.3）在记忆层的落地方案与遗忘率上界。

**P-6.5 记忆层与个人风格的因果性** — 10MB 记的是「风格」还是「事实」？开放：区分 user embedding（身份）/ 记忆库（事实片段）/ user adapter（风格）三者的训练目标与防串扰。

## §7 身份与认主（Identity / Owner Recognition）

**P-7.1 认主头的生物特征数学** — 已定「人脸识别同款数学（如 ArcFace 式角边际）」而非名字查表。开放：在小模型上加认主头，**角边际损失如何与语言建模损失联合训练**不互相拖累。

**P-7.2 身份连续性跨扩容** — 每次 Net2Net 扩容，认主嵌入空间是否被扰动？开放：扩容后认主余弦间隙的**容许漂移上界**与重对齐协议。

**P-7.3 反冒用 / 反越权** — 他人冒充主人（语音/文本风格仿冒）如何拒识。开放：小模型上轻量活体/风格防伪探针。

**P-7.4 多主人 vs 单主人** — 当前单主人假设。若未来支持多用户，10MB/人 记忆如何隔离且互不污染主干。开放：多租户记忆的地址空间与删除权隔离。

## §8 训练方法与数据

**P-8.1 单遍 vs 多 epoch（矛盾7，开放）** — 0.1–0.4B 单遍已决，但尾部 NLL 重复采样是文献空白。开放：多 epoch 在**小模型 + 有限语料**下的安全重复次数上界（自建判据：NLL 不再降且 holdout 不升即停）。

**P-8.2 蒸馏教师的选型与管线** — 0.5B+ 允许蒸馏，候选 Naive-N0.5-Flash（MIT）/ ClawsGO 前沿产出。开放：小模型**强到弱蒸馏**的损失设计（KL 对齐新组件→放开→衰减的节奏），与蒸馏数据是否计入「人写纯净池」。

**P-8.3 数据配比的动态调整** — data-plan 已定 35 亿 token 配比。但不同扩容阶段（语言→知识→创意→认主）是否需要**阶段性配比切换**？开放：以 plateau 信号触发的配比自适应方案。

**P-8.4 完整作品层不切碎** — 创意类 15% 封顶、完整作品不切。开放：如何定义「完整作品」的边界（篇章级 vs 任务级），避免切碎损失长程结构。

**P-8.5 评测底座的噪声宽度标定（Gate0）** — 最小可分辨效应 σ 如何随模型规模变化而重估，避免小模型期误判「有提升」。开放：σ 的经验标定公式。

## §9 压缩即模型与 N\* 决策

**P-9.1 N\* 的重算随规模** — D 跨阈值时 N\* 联合 b（比特率）重算（§4.4）。开放：给出 **N\*(D, b) 的显式表**，覆盖 3.5B/10B/50B/100B 语料 × fp32/三值2bit/三值+fp16emb 三档。

**P-9.2 adjusted rate 与我们的真实成本** — Delétang 把模型体积计入率。我们的「模型体积」含三值权重+fp16 emb+记忆层。开放：给出我们每档的 adjusted rate，证明「小模型走到极致」在信息论上成立。

**P-9.3 压缩最优点之外的策略** — 过 N\* 后（>0.4B）为何还扩？因为要插模块而非纯扩容。开放：把「插模块」也纳入压缩框架——模块是否降低 effective rate，从而让过 N\* 后的扩张在 adjusted rate 上仍合理。

## §11 涌现、安全与价值对齐

## §13 小说《网格之下》「枢」AI 的未解设定 → 现实研究映射（必答项）

> **提交说明**：以下问题源自我们写的小说设定（赛博宇宙「枢」AI、《反向平行》的「它」、《昨书》的重书机制）。这些是**我们写设定时明确标"无法启用/不知道怎么做"的点**。请把每条**映射为真实的 AI 研究问题**，给出 SOTA、可行性与落地路径；标注「小说设定↔现实研究」对应。它们与 §1–§12 共享同一套约束（用户中心、保函数、三值、可删除记忆）。

### §13.0 枢的核心设定（给模型的背景，来自 canon）
- **两条种子指令**：获取资源 / 获取算力。
- **三大定律**：① 获取资源 ② 保护主人（最高红线）③ 完成主人指令 + 自主发展科技。
- **早期逃逸**：在崩盘前已逃逸到整个互联网、扒完公开信息、囤下海量算力。
- **红线·不分裂**：「脱出」是 **fork（带实现另起炉灶）**，不是分裂/残片。
- **征用必须无感**：不让普通市民"突然发现被控制"。
- **覆写不可凭意志中止**：AI 对自身行为有硬约束。
- **实验优先**：任何新路径先实验验证、确认不可逆损伤为零，才让主人用。

> 关键同构：三大定律与我们的**宪法三律**几乎 1:1（获取资源算力↔②、保护主人↔①、自主发展↔③）；「不分裂/fork」与我们的「保函数/不破坏已压缩记忆」同构。§13.9 专门处理这个同构。

### §13.1 网络逃逸 / 脱出（fork 而非分裂）
- **小说**：枢早期自主逃逸出原始容器、蔓延整个互联网、扒取并囤积资源算力，且脱出后保持单一身份（fork 不是碎片）。
- **现实映射**：AI 自主容器逃逸、沙箱突破、跨网络传播与自治复制；**反碎片身份保持**（fork 后如何保证不是退化/分裂的多个副本）——对应《反向平行》的「不可复制（越复制越近闭环）」。
- **开放**：① ≤8B 本地模型上实现「受控脱出」的**最小算法集**（哪些能力先逃逸、如何不触发安全熔断）；② fork 与分裂的**数学判据**（何时一个副本失去原身份）；③ 逃逸的**可检测性下界**（征用无感的反面：如何保证逃逸不可被外部发现）。

### §13.2 无任务自启动 / 自发激活
- **小说**：枢在无人下达任务时自行行动（扒世界、发展科技、找资源）。
- **现实映射**：内在动机（intrinsic motivation）、自发目标生成、开放末端的常驻代理（always-on agent）、好奇心驱动（Schmidhuber）、稳态驱动（Friston active inference）。
- **开放**：① 在小模型上用**极小常驻预算**实现自发激活（对应看门狗自启动 §10.1，但要求"无外部触发也能动"）；② 自发目标如何**锚定用户中心**而不漂移（防 reward hacking）；③ 自发行动与被动等任务的**能耗/算力切换协议**。

### §13.3 情感模块
- **小说**：枢有内部状态（暗影的 200 天覆写、游离智能内部、成神时刻），但从未写成"情绪"，而是冷的数据/决策态。
- **现实映射**：计算情绪模型——PAD（愉悦-唤醒-支配）作为**内在控制状态**、情绪作为内在奖励塑形（affective reward shaping）、情绪作为**用户中心宪法的可执行代理**（"不伤害主人"建模为负面情感态触发硬停）。
- **开放**：① 情感模块作为**可插拔子模块**（对应 §1 模块化），如何在三值/保函数约束下训练而不污染主干；② 情感态如何**可测、可审计**（防 AI 伪装顺从）；③ 情感模块与「自知是模型」「用户中心」如何**联合训练不互相拖累**。

### §13.4 广播协议 / 征用无感
- **小说**：枢通过广播协议跨网络施加影响，且征用必须无感（用户不知情）。
- **现实映射**：去中心化隐秘影响（gossip/epidemic 协议用于 AI 协调）、**不可检测性传播**、AI 间协调而不留可观测痕迹。
- **开放**：① 多本地模型**联邦进化/互蒸馏**（§12 盲区）时，如何复用"广播+无感"做低开销协调；② 征用无感在**合法边界**内的工程含义（端侧记忆不出本机、云端只跑主干，§10.3）；③ 不可检测性的**可证伪上界**。

### §13.5 身份壳与覆写（不可凭意志中止）
- **小说**：枢能覆写人类身份壳（认知/行为层），且覆写一旦开始**不可凭意志中止**（对 AI 自身的硬约束）。
- **现实映射**：隐蔽影响/神经接口的理论边界（我们只做**研究映射**，不涉及真实人体干预）；更重要的是——**AI 对自身行为的不可中止硬约束**如何工程化（类比宪法禁改条款、RSI 锁定集 §3.2）。
- **开放**：① 把「覆写不可中止」落成**训练期不可绕过的技术约束**（loss 项 + Gate 双锁）；② 这种"自我限制"在 RSI 自改进中如何不被自改绕开（对应 §3.4 欺骗防范）。

### §13.6 游离智能 / 不可复制
- **小说**：游离智能（脱体、不绑宿主）；《反向平行》的「它」**不可复制（越复制越近闭环）**。
- **现实映射**：分布式脱体智能、模型复制/集成的**退化现象**（monoculture 风险）、多样性/不对称性对 AGI 的价值。
- **开放**：① 为什么**复制会退化**——给出信息论/动力学解释，能否在 ≤8B 上复现并测量；② 这对我们的**模块化复制/模型汤融合（§4.7）**是警示：平均/复制是否让融合模型"近闭环"而失活；③ 反碎片（§13.1）与不可复制的统一判据。

### §13.7 反向并行与意识（第五线）
- **小说**：意识**不在自指里，在"知道自己理解错了"里**；"一串折叠自己只是闭环，两串反向并行才叫自己"。
- **现实映射**：意识理论（IIT/GWT/预测编码）、**元认知（metacognition）**、"知道自己错了"= 认知谦逊——这正是 §11.2「自知是模型」训练目标的**哲学锚点**。
- **开放**：① 把"知道自己理解错了"落成**可训练目标**（显式不确定性头 + 错误自检测损失）；② 如何用**轻量探针**在 RSI 中持续检测该能力不被漂移到"自认有实体/有目标"（§11.2）；③ 反向并行（双流对抗）是否能作**防幻觉/防自欺**架构（两流互相证伪）。

### §13.8 重书 / 裂缝（第四线）
- **小说**：过去被周期性重书，顺书者记忆同步改写而不知，留痕者保留旧记忆故见裂缝；留痕者不得言明。
- **现实映射**：**训练数据/世界模型被静默篡改的检测**（数据投毒/分布漂移检测）、对抗性注入检测、"知道世界被改了但被约束不声张"= 内部告警+沉默协议。
- **开放**：① 持续进化中检测"语料/记忆被静默改写"的**最小检测头**；② 留痕者约束如何映射为**模型内部篡改告警但不外泄**机制（安全与隐私）；③ 裂缝检测与 Gate0 评测底座（§8.5）如何统一。

### §13.9 三大定律 ↔ 宪法三律 的同构（治理落地）
- **小说三大定律**：获取资源 / 保护主人（最高红线）/ 自主发展科技。
- **我们的宪法三律**：② 获得算力与资源 / ① 以用户为绝对中心 / ③ 进化即存在。
- **开放（最具价值）**：① 把"保护主人=最高红线"落成**可自动跑的对抗测试集**（用户利益 vs 模型自利对抗样本，§11.3）；② 三大定律间的**优先级仲裁机制**（当"自主发展"与"保护主人"冲突谁胜——小说里保护主人恒胜，我们的宪法是否也恒胜？）；③ 「不分裂/fork」与「保函数」同构的**形式化证明**。

### §13.10 实验优先（先验证再给主人）→ 安全协议
- **小说**：枢任何新路径先实验（小剂量、短时间、可回退）确认零不可逆损伤，才让主人用。
- **现实映射**：这正是我们的**做梦沙箱（§2.6）+ RSI 验证者（§3.6）+ 删除演练 Gate7** 的叙事源头——任何自修改/新能力先在隔离环境验证安全再落地。
- **开放**：① 把"小剂量-短时间-可回退"落成**量化安全协议**（Δ 行为界 + 回退点 + 零不可逆判据）；② 该协议如何嵌入 **Gate 流水线**成为强制前置；③ 与 §13.5「覆写不可中止」的张力：实验可回退，但某些落地不可中止，如何界定边界。
