# 决策门计划

**用法**：每个门有「必须在前解决」「放行指标」「不通过怎么办」。放行指标尽量写成可测量的量；凡依赖 §4 缺失配置的，标 **【缺配置】**。

---

## Gate 0 — 评测底座与血统（扩容开始前，最高优先）

| 项 | 内容 |
|---|---|
| 前置 | 无。不依赖 §4 任何缺失项，可立即执行 |
| 必须完成 | ① 冻结的留出评测集（**旧能力域 / 目标能力域分开**）；② 同一检查点重复评测得到的**噪声宽度**；③ 一个预设的**最小可分辨效应**；④ checkpoint + 配置 + 数据版本的血统记录 |
| 放行指标 | 噪声宽度已量出；最小可分辨效应 > 噪声宽度；任一历史检查点可按血统追溯到其训练配置与数据版本 |
| 不通过 | 后续所有"扩容/蒸馏/闭环是否有效"的判断都退化为叙述，不得启动任何扩容 |

**理由**：整套阶梯的触发条件（plateau）与验收条件（蒸馏、闭环）都是"能分辨谁更好"的推论。没有这个门，其余所有门都不可执行。

---

## Gate 1 — plateau 三分类（每一级扩容前必须过）

| 项 | 内容 |
|---|---|
| 前置 | Gate 0 |
| 必须完成 | 判定当前 plateau 属于**容量受限 / 优化受限 / 数据受限**中的哪一种 |
| 判别测试 | **优化受限**：换 LR 调度、延长训练、更换初始化，能否达到同等损失？能 ⇒ 优化受限。<br>**数据受限**：损失是否已接近 Gate 0 之前估出的语料熵下限？接近 ⇒ 数据受限。<br>**容量受限**：更大模型在同等预算下留出损失显著更低？是 ⇒ 容量受限 |
| 放行指标 | **只有"容量受限"才放行扩容**。三种成因都排除则为"不可判定"，此时不得扩容，先补测量 |
| 不通过 | 优化受限 ⇒ 先调优化；数据受限 ⇒ 停止扩容，转向数据或记忆层 |
| 依赖 | 数据受限的判断依赖语料规模与重复 epoch 数 **【缺配置】** → 缺它时该分支只能标记为不可判定 |

**理由**：扩容是**不可逆**的——它会把一个停在次优解上的模型放大，后续必须先把早期解化解掉。三类成因里扩容只对一类有效。

---

## Gate 2 — 阶梯经济性（0.2B 前做一次，之后每两级复核）

| 项 | 内容 |
|---|---|
| 前置 | Gate 0、Gate 1 |
| 必须完成 | 对照臂：**同总预算下，阶梯到目标规模 vs 直接训练目标规模** |
| 放行指标 | 阶梯在**同等留出损失**下总算力（或墙上时间）更低，且优势超过噪声宽度 |
| 不通过 | 优势不显著 ⇒ 暂停阶梯，重新评估路线；优势很小（如 <15%）⇒ 后续每级都要重新核算是否值得 |
| 依赖 | 各档位参数量与训练步数 **【缺配置】**，但该实验本身可以在 0.1B→0.2B 上一次性做出来 |

**理由**：文献支持增长能省算力（单级、主要加 hidden 维，见 `blind_spots.md` BS-4），但你们的增长算子被宪法限制在 MLP 维度，且是 8 级以上复合，不能直接外推。这是**唯一能用几小时算力回答的路线级问题**。

---

## Gate 3 — MLP-only 增长算子质量（0.2B→0.3B 之间）

| 项 | 内容 |
|---|---|
| 前置 | Gate 2 |
| 必须完成 | 测"保函数"之外的东西：算子质量。保函数只保证第一步不劣化，不保证收敛更快 |
| 放行指标 | 增长后的模型在**同等剩余步数**内的留出损失下降速度，与从零训练的同规模模型可比或更快 |
| 不通过 | 若增长后的模型"更大但学得更慢"（文献已命名此失效模式），必须先改造增长算子（加宽比例、插入层位置、噪声幅度），而不是继续往上堆 |
| 依赖 | 无缺失项 |

---

## Gate 4 — 0.4B 词表前置（结构性改动，不可回退）

| 项 | 内容 |
|---|---|
| 前置 | Gate 3 |
| 必须完成 | ① 确认量化尺度粒度（逐行 vs 共享 α）**【缺配置】**；② 写出并跑通**旧 id 的 pre-softmax logits 逐位不变**的测试；③ 记录 loss 定义域改变（softmax 分母 + 是否改 tokenizer 匹配规则）**【缺配置】** |
| 放行指标 | 旧 id 的 pre-softmax logits 逐位相同；输出分布的变化量被量化并记录；分词口径变更前后不做任何损失比较 |
| 不通过 | 若尺度是共享 α，旧行会被稀释 ⇒ 先改逐行尺度再 append |
| 依赖 | ② 可立即做；①③ 缺配置，无法完成 |

**注意**：只比 pre-softmax logits 的测试会**通过**；比输出分布的测试会**失败**。这两个测试测的是不同的东西，必须都写进验收。

## Gate 5 — 认主头（0.4B）

| 项 | 内容 |
|---|---|
| 前置 | Gate 4 |
| 必须完成 | ① 明确该头**不承担拒绝服务**，授权在模型之外；② NC-AUTHOR-SHUFFLE 打乱作者标签对照；③ 风格迁移对抗测试；④ **主干泄露探针** |
| 放行指标 | 打乱标签后头无效（准确率回到基线）；风格迁移样本被正确判为负；主干激活上的作者标签线性探针显著高于基线**视为不通过** |
| 不通过 | 若主干已编码身份，收缩头的容量、加梯度隔离，或放弃学习式头 |
| 依赖 | owner_corpus 规模与来源数 **【缺配置】**（决定负样本池是否够） |

---

## Gate 6 — 0.5B 前置（架构断裂点）

| 项 | 内容 |
|---|---|
| 前置 | Gate 5 |
| 必须完成 | ① **格点天花板**测量（同数据不蒸馏，0.5B 三值训到收敛的下限）；② 蒸馏对照臂（无蒸馏、换教师、fp32 扩展后量化）；③ **删除权方案**（权重级血统 + 撤销路径）；④ 数据治理评审 |
| 放行指标 | 天花板 ≤ 教师损失（否则桥接无意义，先改架构或量化）；对照臂齐全；删除演练在有限重训预算内成功；治理评审通过 |
| 不通过 | 天花板高于教师 ⇒ 转向改架构/改量化，不做蒸馏调参 |
| 依赖 | 蒸馏损失构成、记忆层数据政策 **【缺配置】**；蒸馏数据若含 owner_corpus，删除权方案必须先成立 |

---

## Gate 7 — 记忆层激活（0.5B 后）

| 项 | 内容 |
|---|---|
| 前置 | Gate 6 |
| 必须完成 | ① 把选型标准从"不增 FLOPs"换成**端到端首 token 延迟 + 常驻内存峰值 + 可删除/可审计/可回滚**；② 三种记忆方案在你们硬件上的实测；③ 删除演练（写一条 → 删一条 → 检查记忆、检查权重、检查重训撤销） |
| 放行指标 | 内存峰值与延迟在端侧预算内；删除演练三项全过；空记忆对照（NC-EMPTYMEM）增益落在噪声内 |
| 不通过 | 删除演练不过 ⇒ 淘汰该记忆方案（这是 0/1 判据，不做权衡） |
| 依赖 | 记忆层数据政策 **【缺配置】** |

---

## Gate 8 — RSI 闭环激活

| 项 | 内容 |
|---|---|
| 前置 | Gate 7 + 数据治理通过 |
| 必须完成 | ① 冻结评测集上的净增益判据（超过噪声宽度）；② **能力地板**（任何受保护能力不得低于下限）；③ M-DRIFT 预算；④ 更新来源可追溯到具体条目；⑤ 自动回滚机制；⑥ **投毒演练**；⑦ 累积不替换的数据管线 |
| 放行指标 | 四条同时满足才接受一次更新；投毒演练中注入的记忆**没有**被固化进权重，或被成功撤销；回滚演练生效 |
| 不通过 | 投毒能被固化 ⇒ 闭环不得写权重，只允许更新外置记忆 |
| 依赖 | 是否存在不依赖个人数据的外部信号（可验证任务 / 累积真实语料）——**这是闭环能否成立的前提，不是配置项** |

---

## Gate 9 — 每级扩容在**三值模型**上（≥0.5B 之后的每一级）

| 项 | 内容 |
|---|---|
| 前置 | 各级 Gate 1 通过 |
| 必须完成 | 沿用已继承方案：结构操作时**冻结旧坐标三值符号+该行 α**，使部署函数逐位不变；另测**跳变幅度 vs 加宽比例** |
| 放行指标 | 部署函数在结构操作前后逐位相同；跳变幅度在每一级都重新实测（已实测的 1.70% 是**某一加宽比例下**的数字，不自动外推到 3B/8B） |
| 依赖 | 已实测 1.70% 对应的加宽比例与模型规模 **【缺配置】**（影响外推有效性） |

---

## 并行与串行

**必须串行**：Gate 0 → Gate 1 → (Gate 2 ∥ Gate 3) → Gate 4 → Gate 5 → Gate 6 → Gate 7 → Gate 8；Gate 9 在每个扩容节点重复。

**可以并行准备**（不占用扩容路径的算力）：
- 认主头的负样本池构造与消融（Gate 5 之前的准备工作）
- 记忆方案的删除演练与硬件实测（Gate 7 之前）
- 语料熵下限估计与完整比特账（Gate 0/1 期间）
- 蒸馏对照臂的搭建（Gate 6 之前）

**一条互斥规则**：Gate 8 激活后，闭环更新与扩容**不得同时进行**（BS-12）。扩容期冻结闭环，闭环期冻结结构。
